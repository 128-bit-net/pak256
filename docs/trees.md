## 気候ごとの木

本体の気候は 8 つ（水・砂漠・熱帯・地中海・温帯・ツンドラ・岩・北極）。木が生えるかどうかは、木の dat の `climates` と、`config/simuconf.tab` の `tree_climates`（全面に生える）・`no_tree_climates`（生えない）で決まる。

| 気候 | 木 | 生え方 |
|---|---|---|
| 温帯 | ケヤキ・スギ・シラカバ | 林と、まばらな木 |
| 地中海 | カサマツ | 林と、まばらな木 |
| 熱帯 | ヤシ・パンヤ | 全面に生える（`tree_climates`） |
| 砂漠 | アカシア | 森と、まばらな木（`no_tree_climates` から外した） |
| ツンドラ | トウヒ | 林と、まばらな木 |
| 北極 | トウヒ | 森と、まばらな木（`no_tree_climates` から外した）。本体は北極の木を、いつも雪の絵で描く |
| 水 | なし | 木の絵が無い。`no_tree_climates` に入れてある（水の上にはそもそも植えない） |
| 岩 | なし | 岩の地面は、岩肌が見える所。木の絵を足していない（`no_tree_climates` に入れてある）。岩場の低い灌木が要るなら別の issue で足す |

- 重みの `distributionweight` は、同じ気候の中の木どうしの出やすさ。温帯は 2:2:1（ケヤキ・スギ・シラカバ）。
- 木の数は地図の重さに直結する（`max_no_of_trees_on_square` など。`config/simuconf.tab`）。
- `tree_climates`・`no_tree_climates` が効くのは、森の外にばらまく木（`fill_trees`。`forest_inverse_spare_tree_density` の本数）と、湿度による配置だけ。**森（`create_forest`・`tool_forest`）は、この 2 つを見ず**、木の絵のある気候（`has_trees_for_climate`）なら作られる。だから砂漠・北極にも森ができる。水・岩に木が生えないのは、木の絵が無いため。将来、岩に木を足すと、岩にも森ができる。
- 検査: `tools/test_trees.py` が、水・岩を除く各気候に木が 1 種以上あることと、`tree_climates`・`no_tree_climates` が木と食い違わないことを確かめる。

## 季節

本体のコードで確かめた（OTRP の `obj/baum.cc`・`bauer/tree_builder.cc`・`descriptor/writer/tree_writer.cc`・`simworld.cc`）。

- 本体の季節は 0 夏・1 秋・2 冬・3 春・4 雪（雪の絵）の 5 つ。月（1 始まりで言うと）は、12〜3 月が冬（2）、4〜5 月が春（3）、6〜9 月が夏（0）、10〜11 月が秋（1）（`month_to_season`。添字は 0 始まりの月で、冬 {0,1,2,11}・春 {3,4}・夏 {5〜8}・秋 {9,10}）。
- **雪（4）を使うとき**: 木の足元が雪線以上のとき、または北極の気候のとき。年じゅうこの絵になる。雪線のすぐ下（1 段下）の木は、夏（季節 0）の間だけ、本体の月（0 始まり）が 5 以下なら春（3）の絵、それ以外（6〜8）は秋（1）の絵になる（雪線をまたぐ木）。
- dat の `seasons` の数で、本体がどの絵を引くかが変わる。
  - `seasons=5`: 5 つとも自分の絵を引く（0 夏・1 秋・2 冬・3 春・4 雪）。
  - `seasons=4`（夏・秋・冬・春）: 雪の絵が無いので、雪（4）は冬（2）の絵を引く（コードのコメントは「春」と書くが、実際は 2）。
  - `seasons=2`（0 夏・1 冬。3 以下は同じ）: **雪（4）のときだけ** 1 の絵を引く。季節の冬（2）は夏の絵のまま。
  - `seasons=1`: 季節の絵が無い。雪線の上でも夏の絵になる。
- 画像の指定は `image[age][season]`。`image[0][0]`〜`image[4][4]` の 25 枚（`seasons=5`）。使わない季節でも、同じ絵を指してよい（makeobj は、その分の画像を pak に書く）。
- 建物（#103）も季節の絵を持つ。本体の側の季節と雪線の決まりは同じ（`simworld.cc` の `recalc_season_snowline`）。

### この pak の季節の絵

| 種類 | seasons | 夏 | 秋 | 冬 | 春 | 雪 |
|---|---|---|---|---|---|---|
| ケヤキ・シラカバ | 5 | 緑 | 橙・黄に色づく | 葉を落とし、枝に雪 | 若葉の明るい緑 | 葉を落とし、枝にたっぷりの雪 |
| スギ | 5 | 濃い緑 | 夏と同じ | 雪が載る | 夏と同じ | 全体が雪をかぶる |
| トウヒ | 5 | 濃い緑 | 夏と同じ | 雪が載る | 夏と同じ | 全体が雪をかぶる |
| カサマツ・ヤシ・パンヤ・アカシア | 2 | 緑（冬も同じ） | | | | 雪が載る |

- 地中海・熱帯・砂漠の木は、季節で見た目を変えない（冬も葉がある）。雪線の上の高地に生えたときだけ雪が載る。
- 冬（2）と雪（4）は違う絵にした（冬は雪の量が少し少ない）。落葉樹は、冬も雪も葉を落とす。

## ゲームで確かめる

`tools/tree_check.py` が、気候ごとの区画に林を置き、ゲームの月を進めて夏・秋・冬・春を撮る（[game-check.md](game-check.md) の `Game` の上）。撮った画像と手順は [records/2026-11-26_tree-seasons.md](records/2026-11-26_tree-seasons.md)。本体の季節は月だけで決まり、スクリプトから季節を直に指定する手が無いので、月が目的になるまで早送りする。

## 絵の形

- 256px のセルを横に age の 5 つ、縦に見た目（`looks`）の数だけ並べたシート（幅 1280、高さは 256 の倍数）。行の並びは種類ごとに違う（ケヤキ・シラカバ: 夏・秋・冬・春・雪の 5 行、スギ・トウヒ: 夏・冬・雪の 3 行、ほか: 夏・雪の 2 行）。`image[age][season]` が引く行は、表（`.yaml`）に書き出してある。根元はセルの (128, 192)（地面の菱形の中心。[ground.md](ground.md)）。
- `draw_trees.py`（MIT）が PNG と表（`.yaml`）を書き出す。書き出した物もコミットしてある。作り直すとき: `python -X utf8 objects/scenery/trees/draw_trees.py`（Pillow だけで動く）。
- 高さは、描いた後に測って、表の値（成木の高さ × 育ち）に合うまで補正して描き直す（`render_fitted`）。落葉樹の冬の枝は、夏の樹冠の外接枠の中に広げるので、夏と同じ高さ・幅に収まる。
- `tools/test_trees.py` が、各行・各 age の高さと成木の幅が上の表の ±5% に収まることと、特別な色が混じらないこと、表（`.yaml`）の気候・季節・画像の参照が合うこと、各気候の木と `simuconf.tab` が食い違わないことを確かめる（絵を描き直したら流す）。
- 色は特別な色（makeobj が別の意味に読む色）を避ける。縁は縮小でなめらかにしてから、半透明を切る。
