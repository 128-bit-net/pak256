# AMI の車庫・停留所・標識のカーソルのずれ（#76）

日付: 2026-11-26。issue: [#76](https://github.com/128-bit-net/pak256/issues/76)。

## 経緯

- 車庫・標識・道路の停留所を置くときのカーソルが、置く絵から右下へずれた（256 の vendor の pak は 2 倍の作りで、約 +128・+190 px。AMI の `ami_dat.py` が、絵には offset（例 `-64,-96`）を付けるのに `cursor=` には付けていなかった）。
- 直しは AMI の側（128na/simutrans-addon-dev#282・PR #286 の 7202e49）。AMI の main は 0b69844。
- `vendor/ami/build.env` の `AMI_COMMIT` を 0b69844 に上げ、`tools/build_ami256.py build --version alpha.5` で 256 版を組み、`vendor-ami-256-alpha.5` に上げて `ami.env` を書き換えた。

## 確かめたこと

- 組んだ zip を alpha.3 と比べた（`build_ami256.py compare`）。pak の名前と数（7 つ・物の数）は同じ。大きさも同じ。pak の中身は 7 つともバイト単位で違うが、差の中身（カーソルの offset のほか、#288 の歩道のノイズなど 8801a1e から 0b69844 までの AMI の変更）は分けて確かめていない。
- 道路（`ami_road_local`）の端に車庫、途中に停留所、道路に標識を置いて、置くときのカーソルが絵と同じ場所に出ることを撮った（`2026-11-26_ami-cursor-screens/`）。
  - `depot.png`: 道路の端に置いた車庫。カーソルの色づけが、車庫の置いた升の絵に重なっている。
  - `stop.png`: AMI の停留所（`ami_road_bus_stop`）と、次の升のカーソル。カーソルと絵が同じ場所にある。道路の停留所は #94 で pak256 の物に戻ったので、この停留所は同梱の物では使わない（AMI の側の直しの確認として残す）。
  - `sign.png`: 置いた標識と、カーソルの升（標識のカーソルは升の菱形）。
- 起動はポート 47881 の `tools/game.py --interactive`。ツールバーの窓の位置が、起動のたびに上や下に変わった（`gui.click` の座標は、撮って確かめてから押す）。

## 確かめていないこと

- alpha.3 で同じ場面を撮った比べ（ずれていた画像）。ずれの再現と原因は [#76 のコメント](https://github.com/128-bit-net/pak256/issues/76)に残してある。

- 操車場（yard）・8 つの向きごと・左右の通行・128 の側。
- 標識だけのカーソルの細かい位置（升の菱形なので、ずれがあっても見分けにくい）。
- 保存データの読み込み。
