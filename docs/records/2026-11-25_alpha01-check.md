# α0.1 の起動の確かめ（2026-11-25）

[#11](https://github.com/128-bit-net/pak256/issues/11)。main の先頭（`1c1820d`）の CI が作った配布の zip（`pak256-dev-1c1820d.zip`、AMI の 256 版の道路入り）を、そのまま展開して OTRP v64（`sim-WinGDI64-OTRPv64.exe`）で起動した。`pak256poc` からは何も借りていない。

## 手順

1. CI の artifact `pak256-zip` を取り、展開した `pak256/` を作業フォルダの `pak/` にした。
2. 検証環境（`addon_check`）の実行ファイル・DLL・`themes/`・`font/`・`text/`・`script/` を写した作業フォルダを作った。`settings.xml` は写さない（送信用の記録を避けるため）。
3. 起動: `-singleuser -set_workdir <作業フォルダ> -objects pak/ -load flat_512_left_v64 -mcp-port 47881 -debug 2 -lang en`。ゲームのプロセスは PID を指定して終了した。
4. 平らな保存データに `command_x(tool_add_city).work(player_x(0), coord3d(256,256,0), …)` で街を 3 つ置き、森は `tool_forest`（x 222〜246、y 256〜276、温帯の地面）で作った。画面は `gui.set_zoom`・`gui.jump` と `capture_screen`。

## 結果

- 起動して保存データを読み、街が建った（街 3 つ（Himeji・Mito・Niigata。画像は Himeji と Niigata）。役場・住宅・AMI の道路が出る）。木は 3 種（`pak256_cedar`・`pak256_birch`・`pak256_zelkova`）が 238 本生えた。本体が止まる・ダイアログが出ることは無かった。
- 起動のログの `ERROR` は、`symbol.BigLogo.pak` が無い 1 件（起動画面のロゴ。roadmap の「無くてもよい」物）。`Warning` は `settings.xml` が無いこと・音楽が無いこと・`threads` の値だけで、pak に起因する物は無い。
- 街を置いた直後の道路は建設中の黄黒の縞で、時間が進むと道路になった（画像は撮っていない）。
