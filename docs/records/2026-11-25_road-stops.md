# 仮の停留所をゲームで確かめた記録（2026-11-25）

## 背景

[#44](https://github.com/128-bit-net/pak256/issues/44) の仮のバス停・トラックの荷役所（[stations.md](../stations.md)）が、道路に置けて駅になるかを OTRP v64（`sim-WinGDI64-OTRPv64.exe`）で確かめた。

## 手順

1. `python -X utf8 tools/build.py` で組む（AMI の 256 版は Release の zip から取った）。makeobj のログに `Warning`・`ERROR` は無い（`station.road_stops.pak` ができた）。`tools/test_*.py` は 111 件通る（main に取り込んだ後）。
2. 検証環境（`addon_check`）の実行ファイル・DLL・`themes/`・`font/`・`text/`・`script/` と、保存データ `flat_512_left_v64` を写した作業フォルダに、自前の pak 全部と `ami_road.pak`、`pak/config/*.tab` を置いた（`settings.xml` は写していない）。
3. 起動: `-singleuser -objects pak/ -noaddons -load flat_512_left_v64 -freeplay -mute -mcp-port 47862 -screensize 1700x950`。
4. 道路は `command_x(tool_build_way).work(player_x(0), coord3d(x,y,0), coord3d(x2,y2,0), "ami_road_local")`、停留所は `command_x(tool_build_station).work(player_x(0), coord3d(x,y,0), "pak256_bus_stop")`（道路の種類は名前から引かれるので、道路の種類の番号は付けない。`"1,pak256_bus_stop"` は失敗した）。

## 結果

- **道路に、バス停・荷役所が置けた**: 東西の道の途中にバス停 3 つを並べ、南北の道の途中にバス停 1 つと荷役所 2 つ、東西の道の端に荷役所 1 つ（座標は下の表）。置くと駅（`halt`）ができる。
- **扱う貨物が dat のとおり**: バス停は旅客を受ける（`accepts_good(Passagiere)` が true、`Kohle` は false）。荷役所は貨物の `Kohle` を受け、旅客は受けない。どちらも容量は 64（`level` 2 × 32）。
- **向きの絵**: 本体の「端」は、道路の行き止まりでなく、並んだ停留所の連なりの端（レビューで指摘され、画面で確かめた）。1 つだけ置くと両端（6・7）の絵が出て、3 つ並べると真ん中は帯が続き（0・1）、端に小さな縁が出る。南北の道・東西の道の両方の向きが出た。連なりの端が南・東か北・西か（2〜5 の個別の向き）は、画面から見分けていない。
- 画像（1930 年春。`gui.set_zoom(3)`。作業フォルダの `pak/config/simuconf.tab` の末尾に `day_night_shift = 0` を足して、昼夜の切り替えを止めた）:

## 確かめていないこと

- **駅の範囲（集客の範囲）の表示。** 範囲は、置くときのカーソルや駅の窓で見える物で、スクリプトから出せなかった。駅ができて（`halt`）、旅客と貨物の容量があることまでは確かめた。ユーザーが、ツールバーで停留所を選んでカーソルを道路に当て、範囲の色が出るかを確かめる。
- **置くときのカーソル。** dat に `cursor` を書いていないので、ツールバーから置くときのカーソルが出るかは未確認。
- **ツールバーの道具（アイコン）の見え方。** アイコンは 256px のセルで、GUI の決まり（128px の元を縮める。[gui.md](../gui.md)）と違う。縮めたときの見え方も未確認。 ツールバーに停留所の項目が出て、道具の絵が見えるか。上の写真はスクリプトで置いたので、ツールバーからは置いていない（ツールバーのアイコンを撮れていない）。
- **旅客・貨物が実際に運べること**（車両が無い。#41・#42）。
- 道路の幅に合った絵の位置。絵は道路の幅を 9m ほどと見て置いたが、AMI の道路の幅と細かくは合わせていない。歩道が道路の脇の帯に少し重なって見える。
- 冬・雪の気候。
- OTRP v64 だけで確かめた。本家 125.0.1 は未確認（[concept.md](../concept.md) の F）。
