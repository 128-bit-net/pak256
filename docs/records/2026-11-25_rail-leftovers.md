# 線路の撤去のアイコン・灰色のアイコン・曲がりでの車両の見え方の記録（2026-11-25）

## 背景

[#71](https://github.com/128-bit-net/pak256/issues/71)。#46（PR #69）の「確かめていないこと」に残った 3 件を片付けた。OTRP v64（`sim-WinGDI64-OTRPv64.exe`）、保存データ `flat_512_left_v64`、`tools/game.py` の `Game`（昼夜は止める。`gui.set_zoom(3)`、画面は 1600x900）。

## 1. 線路の撤去のアイコン

- 線路のツールバー（`toolbar[3]`）の撤去 `toolbar[3][6]=general_tool[17],20,,2` は、道路の撤去と同じ `bar` 20（道路の帯に赤い ×）だった。
- `bar` 46 を足し、線路の帯（道床・まくらぎ・レール）に赤い × の絵（`gui_icons.py` の `g_rail_x`、`rail`）にして、`toolbar[3][6]` を `general_tool[17],46,,2` に変えた。線路の帯の描き方は `rail` に切り出し、`g_rail_tool` も同じ関数を使う。
- 画面: `rail_before.png`（直す前。道路の絵）・`rail_after.png`（直した後）。道路のツールバーの撤去は変えていない。

## 2. 灰色のアイコン

- 灰色のアイコンは、メニューの設定の空きではなく、**pak256 の停留所の道具の絵**（`pak256_bus_stop`・`pak256_truck_stop`・`pak256_train_station` の `icon`）だった。道路のツールバーに 2 つ（バス停・荷役所）、線路のツールバーに 1 つ（駅）。ほかの灰色は無かった（`general_tool[14]` は線路・道路の最後の「既定の線路・道路」の道具で、AMI の線路の絵が出ている）。
- 原因（推測。画面の証拠は「絵が枠の外へずれ、四角にしたら枠が埋まった」まで。本体の `display_fit_img_to_width` と makeobj の透明な縁の切り詰めの読みは未確認）: 道具の絵は 256px のセルに停留所だけを透明な背景に描いていた。本体は絵の見える範囲だけを縮めて、その範囲の始まりの位置に置くので、停留所の絵はアイコンの枠の外（下）に出て、枠は灰色の空きになった（`road_before.png` の右寄りの灰色と、その下に小さく出た停留所）。
- 直し方: アイコンを 192px の角丸の四角（地の色に停留所の絵を収めたもの）にして、2 行 0 列のセルの左上の角から置く（`draw_stops.py` の `tool_icon`）。192px なら本体が 1/4 に縮めてちょうど 48px（`icon_height`）になり、枠が埋まる。`tools/test_stations.py` が、四角に透明色が無いこと・192px の外に絵がはみ出さないことを検査する。
- 画面: `road_after.png`・`rail_after.png`（右寄りに、青い四角にバス停・荷役所・駅が出る）。

## 3. 曲がり・坂での車両の見え方

手順: `tools/vehicle_check/rail_curve_run.py`（ポート 47842）。`rail_curve.nut` が、コの字の線路（北の辺 y=60 の x=40〜70、東の辺 x=70 の y=60〜70、南の辺 y=70）に、北と南の駅（3 タイルずつ）・車庫・気動車 + 付随車の 1 編成を置く。曲がりは東の 2 つの角。北の辺の x=60〜63 に高さ 1 の丘（手前と先は 1 段の坂）。編成が角・丘に近づいたら、先頭のタイルを真ん中にして撮った（21 枚）。

| 画像 | 見所 |
|---|---|
| `corner_ne.png` | 北東の角（70,60）。先頭の車が角のタイルで縦の斜めに向き、後ろの車が横の斜めの線路に残る。縦の車体は 1 タイルの角の外へ、草地にはみ出す |
| `corner_se.png` | 南東の角（70,70）。横向きの車が角の線路の外へ、左の草地にはみ出し、後ろの車は斜めの線路の上 |
| `hill_down.png` | 丘の先の下りの坂。2 両が段差の上と下に分かれ、継ぎ目に段ができる |
| `hill_up.png` | 丘の手前の上りの坂。同じ |

分かったこと:

- 曲がり: 車体は 1 枚の絵で、進む向きの斜めに描かれる。AMI の 90° の曲がりは 1 タイルの中で折れるので、20m（`length=12`、絵は 19.8m）の車体は角のタイルの外へ出る。連結の継ぎ目は、前の車が曲がっている間は直線の位置と食い違う。曲がりを抜けると直る。
- 坂: 車体は水平のまま。1 段の坂をまたぐ継ぎ目に段差が出るが、車輪の下端は前後とも線路の上に乗り、地面に埋まったり浮いたりしなかった。
- **直さなかった理由**: 1 両 1 枚の絵は本体の決まり。はみ出しを無くすには、車両を短くして両数を増やすか、曲がり用の絵を車両ごとに足す必要があり、仮の絵の段階では釣り合わない。見える形は上の画像のとおり。本格的な車両を描くときに決める（[roadmap.md](../roadmap.md) の「車両の顔ぶれと時代」）。

道具について: 線路を敷いた後に地面を上げても、本体は上げなかった（`command_x.grid_raise` は成功の値を返すが地面は変わらない）。丘は先に地面を上げてから、線路を 1 タイルずつ敷く（長く敷くと、本体が丘をよける経路を選び、線路が丘の脇を回った）。
