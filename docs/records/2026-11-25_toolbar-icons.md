# ツールバーのアイコンの絵をゲームで確かめた記録（2026-11-25）

[#66](https://github.com/128-bit-net/pak256/issues/66) で、ツールバーのアイコンを「番号つきの色の四角」から、何の道具か分かる絵にした。決め事は [gui.md](../gui.md) の「アイコンの絵」。

## 手順

1. `python -X utf8 objects/gui/draw_gui.py` で PNG を書き出し、`python -X utf8 tools/build.py` で組んだ。makeobj のログに `Warning`・`ERROR` は無い（0 件）。
2. `tools/game.py` の `Game`（OTRP v64、保存データ `flat_512_left_v64`、ポート 47866）で起動し、`gui.set_zoom(3)` にして、`gui.click(x, 24)` で上のツールバーの項目を押し、`gui.close_all_windows()` を挟んで 1 つずつ `capture_screen` で撮った。`icon_height` は 48。
3. 画像は上のツールバーとサブメニューの部分だけ切り抜いた（画面は 1600x900）。

## 分かったこと

- `gui.click` の 3 つめ以降は真偽値（`shift`・`ctrl`）で、数を渡すと `Call function failed` になる。座標だけ渡す。
- サブメニューを開いたままで次を押すと、前のサブメニューの端が残って写るので、`gui.close_all_windows()` を挟む。
- 編集のサブメニューは、特別のサブメニューのプレイヤーの切り替え（`simple_tool[5]`）を押して公共プレイヤーにすると開ける（本体は公共プレイヤーのときだけ `EDITTOOLS` を出す）。
- 48px に縮めても、道具ごとに見分けがつく。細い線の絵（問い合わせの `?`・坂の向きの文字）は小さい。

## 確かめていないこと

- 編集のサブメニューの 11 個目（`dialog_tool[35]`、地面の物の編集の茂みと鉛筆）は、画面に出なかった（10 個だけ出た）。本体が出さなかった理由は未確認（128px の元は `10_`）。
- 気候の道具のうち、水位・気候の道具を実際に押したときの動き（アイコンだけ確かめた）。
- 夜の見え方・冬の見え方（アイコンは季節で変わらない）。
