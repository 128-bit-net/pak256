# α0.2 の起動と運送の確かめ（2026-11-25）

[#45](https://github.com/128-bit-net/pak256/issues/45)。main の先頭（`6c365f4`）の CI が作った配布の zip（`pak256-dev-6c365f4.zip`。CI の run 45564781728 の artifact `pak256-zip`。pak 14 個。AMI の 256 版の道路と、仮の車庫・バス停・荷役所を含む）の `.pak` と `ami_license.txt` を取り出し、OTRP v64（`sim-WinGDI64-OTRPv64.exe`）で起動した。`pak256poc` など別の pak は借りていない（`--extra-pak` を使わない。検証環境から写すのは、`tools/game.py` が決めた実行ファイル・`config/`・`font/`・`themes/`・`text/`・`script/`・`music/` と保存データだけ）。α0.1 の確かめと違い、zip を丸ごと展開した形では起動していない（`config/`・`text/` は main と同じ内容のこの worktree の物を使い、zip 内の物は使っていない）。車庫（#58）を置いてバスと石炭のトラックを買い、旅客と石炭を運んで収入が出ることを確かめた。

## 手順

1. CI の artifact `pak256-zip` を取り、zip の中の `*.pak` と `ami_license.txt` を、作業用の `build/pak/` の形に取り出した。`config/`・`text/` は main と同じ（この worktree の物）。
2. [run.py](2026-11-25_alpha02-screens/run.py)（`tools/game.py` の `Game` を、取り出した pak の場所を `build=` で渡して使う）。検証環境 `addon_check`、保存データ `flat_512_left_v64`、ポート 47885、昼夜は止めてある。
3. [setup.nut](2026-11-25_alpha02-screens/setup.nut): 温帯の平地（x<256）に東西の道（`ami_road_local`、y=60、x=50〜150）を敷き、その北に街 2 つ（60,57 と 100,57。`tool_add_city`。**人口は足さない**）と、炭鉱（118,57）・発電所（138,57）を置いて `tool_link_factory` でつなぐ。道の上に、バス停（`pak256_bus_stop`）を街の中心の南に 2 つ（59,60 と 100,60。中心の南の 60,60・61,60 は「No through station here!」で置けず、隣へずらした。理由は未確認）、トラックの荷役所（`pak256_truck_stop`）を炭鉱の脇（119,60）と発電所の脇（139,60）に置く。道の南の脇（125,61）に道路の車庫（`pak256_road_depot`）を置き、**その車庫で買った**バス（`pak256_bus`。2 つのバス停を往復）と石炭のトラック（`pak256_coal_truck`。炭鉱で 20% 積み、発電所で降ろす）を 1 台ずつ出した。
4. 本体の速さ 128（約 7 年半を 6 分）で 1930 年 1 月から 1937 年 7 月まで走らせ、15 秒おきに編成の位置・収入・収益を読んだ（[run.log](2026-11-25_alpha02-screens/run.log)）。最後に速さ 1 にして、昼の絵を撮った（`gui.set_zoom(3)`、1600x900）。

## 結果

- 借り物なしで起動し、街が建ち、道路・車庫・バス停・荷役所・炭鉱・発電所が置けた。道路・街・炭鉱・発電所・荷役所・車庫の `command_x` の戻り値はどれも `null`（成功）。バス停は 60,60 と 61,60 だけ置けなかった（スクリプトは置けた時点で試すのをやめるので、ほかの場所は試していない）。2 回目の実行では、本体が最後まで止まらなかった（1 回目の停止は「確かめていないこと」）。撮影のたびにダイアログを閉じているので、通知が出たかは見ていない。起動のログの `ERROR`・`Warning` は読んでいない。
- **バスが旅客を運んで収入が出た**: 2 つのバス停の間を往復した。財務の窓（`6_finances.png`）の旅客の収入は、1937 年（7 月まで）が 27.39$、前年度が 77.13$、輸送した旅客が 37 人と 104 人。
- **石炭のトラックが石炭を運んで収入が出た**: 炭鉱の荷役所で積み、発電所の荷役所で降ろした。財務の窓の貨物の収入は、1937 年（7 月まで）が 371.19$、前年度が 597.32$、輸送した貨物が 174 と 280。産業一覧（`8_factories.png`）の発電所が「(354+36, -, 50)」（括弧の読みの形式は未確認。入力の在庫と、荷役所で待つ分を含むかもしれない）、炭鉱が「(-, 26, 50)」。
- 編成一覧（`7_convoys.png`）の収益は、バスが −603.24$、石炭のトラックが +228.15$。**全体は赤字**（財務の窓: 1937 年の運行費 −772.80$、維持費 −3,364.00$、運用利益 −3,738.22$）。バスは運ぶ旅客が少なく、運賃収入（`get_revenue()` の読みは月ごとに 0〜13。単位は未確認で、財務の窓の年 77.13$ と突き合わせると、1 ドル単位に近い）が運行費（月およそ 100）に届かない。編成一覧の収益は、運賃収入から車両の運行費だけを引いた値で、施設（道路・停留所・車庫）の維持費は入っていない。運賃・運行費・維持費・街の旅客の量のつり合いは、roadmap の段階 4 で見直す。なお、バスの確かめ（[記録](2026-11-25_bus-mail.md)）は同じ `get_revenue()` を 1/100 単位として書いており、単位の読みが食い違う（未確認）。プレイヤーの所持金は −1.4 億$ の保存データ（窓に「破産しました」）なので、黒字・赤字の表示は参考値。
- 走る・止まる: 2 台とも道路（車線）に乗って走り、バス停・荷役所で止まって積み降ろしをした。
