# 街の成長をゲームで確かめた記録（2026-11-25）

## 背景

[#30](https://github.com/128-bit-net/pak256/issues/30)。[#8](https://github.com/128-bit-net/pak256/issues/8) では「街は旅客などの輸送が無いと増えない」と考え、人口をスクリプトで足して育ちを見た（[記録](2026-11-25_town-buildings.md)）。バスとバス停（#41・#44）ができたので、人口を足さずに、街が育つ条件を OTRP v64 で確かめた。

## 手順

1. `python -X utf8 tools/build.py` で組む（makeobj のログに `Warning` は無い）。
2. [run.py](2026-11-25_town-growth-screens/run.py)（`tools/game.py` の `Game` を使う。検証環境 `addon_check`、保存データ `flat_512_left_v64`、昼夜は止める）。車庫は pak256・AMI の 256 版にまだ無いので、`pak256poc` の `infrastructure.depots_rail_road_tram.all.pak`（pak128 の物）だけを `extra_paks` で借りた（コミットしない）。
3. [setup.nut](2026-11-25_town-growth-screens/setup.nut): 温帯の平地（x<256）に、東西の道（`ami_road_local`、x=50〜110・y=60）を敷き、道の北に街を 2 つ（60,57 と 100,57）置く。**人口は足さない**。街の乱数は固定していない（実行ごとに街の名前と最初の人口が違う）。
4. `debug.set_game_speed(128)` で 1930 年 1 月から 1941 年 5 月（約 11 年）まで早送りし、20 秒おきに各街の人口・建物数・旅客と郵便の統計を読む（`city_x` の `get_citizens`・`get_buildings`・`get_generated_pax`・`get_transported_pax`。2 回目の「停留所なし」からは郵便も）。
5. 3 つの条件を比べた。
   - **バスあり**: 各街の真南の道の上にバス停（`pak256_bus_stop`）を置き、車庫から出したバスと郵便のトラックが 2 つのバス停を往復する。
   - **車両なし（停留所あり）**: バス停だけ置き、車両は出さない（`--nobus`）。
   - **停留所なし**: バス停も車両も置かない（`--nostop`）。道だけ。

- **停留所があれば、街は人口を足さなくても育つ**。人口は約 300 から 11 年で約 400〜650、建物は約 10 軒から 13〜30 軒に増え、集合住宅・長屋・戸建てが道に沿って建った。
- **停留所が無い街は、11 年間まったく育たなかった**。人口も建物も動かない（2 回とも、4 つの街）。旅客は生まれている（1 か月の途中の読みで 50〜100 ほど）が、経路探索に進めないので、満たされた旅客が 0 のまま。#8 の「輸送が無いと育たない」は、停留所が無い場合に当たる。
- **車両なしでも育つ**。車両なしの 4 都市とバスありの 4 都市の増え方は、どちらも街ごとのばらつき（400〜650）の中に入り、バスの有無による違いは読み取れない。
- **原因（ソースで確かめた）**: 本体の成長は、旅客・郵便・貨物の需要のうち「満たされた分」の割合の加重平均で決まる（郵便の重みは `simuconf.tab` の `mail_multiplier` = 20）。旅客の満たされた分には、運ばれた旅客と、**停留所の範囲の中を徒歩で街の中の目的地に着いた旅客**（`HIST_PAS_WALKED`）が入る（郵便も同じ。`simcity.cc` の `city_growth_get_factors`。読んだ本体のソースは OTRP の作業ツリー `issue-25-halt-step` の物で、v64 のタグとの一致は確かめていない）。経路探索は建物の周りに停留所がある旅客だけが行う（`step_passagiere`）ので、停留所が無いと満たされた分は 0 になる。停留所があれば、車両が無くても、停留所の範囲の中で歩いて着く旅客で割合が上がる。
- **停留所から旅を始められた旅客は少ない**: `tr_pax`（`HIST_PAS_TRANSPORTED`。経路が見つかり、停留所から旅を始められた旅客の数で、車両が目的地まで届けた数ではない。復路の分も、相手の街に数えられるので、2 つの街の値は同じになる）は 1 か月の途中の読みで 0〜7、生まれた旅客（50〜150）の約 3%（`tr_pax` の和 ÷ `gen_pax` の和は、1 回目 0.034、2 回目 0.031）。月の途中の値なので、満月の値ではない。バスが実際に走って旅客を降ろしたことは、バスの確かめ（[記録](2026-11-25_bus-mail.md)）の収入で見ていて、ここでは見ていない。

## 確かめていないこと

- **バスだけで街が育つこと**。停留所があれば車両が無くても育つため、バスの寄与は分けて見えなかった。分けるには、歩ける目的地を無くす（家が停留所の範囲から離れた大きな街）か、バスの量を桁違いに増やす必要がある。徒歩の旅客の数（`halt_x` の `get_walked`）と郵便の成長への効きは読んでいない（郵便は 2 回目の停留所なしだけ読み、運ばれた分は 0）。
- 停留所の範囲の外まで広がった大きな街の育ち（11 年で人口 650 まで）。
- 新しい地図の作成画面で街が建つこと（保存データ `flat_512_left_v64` を読み、`tool_add_city` で街を置いた。作成画面はスクリプトで操作できない）。
- 本家 125.0.1（OTRP v64 だけ）。
- 住宅の段が上がって高い建物に建て替わるか（建物の種類ごとの数は読んでいない。画像で見えた範囲）。
- 貨物による成長、右側通行の地図。年代設定が無効の状態だけで確かめた。
- 車庫は pak128 の物を借りた（コミットしていない）。

## 後に分かったこと（道具）

- `run_squirrel` に渡す文字列にバックスラッシュ+n を入れると本物の改行になり、コンパイルが通らない。区切りは `" / "` などで書く。
- 確かめの途中で Python を強制終了すると、ゲームが残り、MCP のポートを握ったまま消えない（このときは 47810 が使えなくなり、47811〜47813 を使った）。
