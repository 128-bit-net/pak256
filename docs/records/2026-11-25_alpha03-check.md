# α0.3 の起動と運送の確かめ（2026-11-25）

[#70](https://github.com/128-bit-net/pak256/issues/70)。main の先頭（`791b44d`）の CI が作った配布の zip（`pak256-dev-791b44d.zip`。CI の run 45595293530 の artifact `pak256-zip`。pak 22 個。AMI の 256 版の道路・線路・車庫と、仮のバス停・荷役所・駅、バス・トラック・気動車・付随車を含む）を展開し、中の `*.pak`・`ami_license.txt`・`config/`・`text/`（**zip の物。この worktree の物は使っていない**）で、OTRP v64（`sim-WinGDI64-OTRPv64.exe`）を起動した。`pak256poc` など別の pak は借りていない。α0.2 の確かめ（[記録](2026-11-25_alpha02-check.md)）に、線路と列車の往復を足した形。

## 手順

1. zip を展開し、`*.pak` と `ami_license.txt` を `build/pak/` の形に、`config/`・`text/` を `Game` の `root` に渡した（`tools/game.py` の `Game(build=…, root=…)`）。
2. [run.py](2026-11-25_alpha03-screens/run.py)。検証環境 `addon_check`、保存データ `flat_512_left_v64`、ポート 47880、昼夜は止めてある。
3. [setup.nut](2026-11-25_alpha03-screens/setup.nut)。
   - 道路: 東西の道（`ami_road_local`、y=60）の北に街 2 つ（人口は足さない）と炭鉱・発電所を置き、バス停 2 つ（59,60 と 101,60。中心の南の 60・61 と 100 は「No through station here!」で、隣へずらした）、荷役所 2 つ、AMI の道路の車庫（`ami_road_depot`）を置いた。その車庫で買ったバス（`pak256_bus`。2 つのバス停を往復）と石炭のトラック（`pak256_coal_truck`。炭鉱で 20% 積み、発電所で降ろす）を 1 台ずつ出した。
   - 線路: 東西の線路（`ami_rail_ballast`、y=110、x=40〜100）に、駅（`pak256_train_station`）を 3 タイルずつ 2 か所（46〜48 と 92〜94）、中ほどの南の脇に AMI の線路の車庫（`ami_rail_depot`）を置いた。その車庫で気動車に付随車をつないだ 1 編成（`pak256_railcar` + `pak256_railcar_trailer`）を買い、2 つの駅の間を往復させた。線路の北に街 2 つを置き、**この 2 つだけ `change_size(300)` で人口を足した**（旅客を出すため。道路の街は足していない）。
4. 建設中の絵が終わるまで `Game.settle(25)`。本体の速さ 128 で 1930 年 1 月から 1937 年 7 月まで走らせ、15 秒おきに編成の位置・収入・収益を読んだ（[run.log](2026-11-25_alpha03-screens/run.log)）。最後に速さ 1 にして、昼の絵を撮った（`gui.set_zoom(3)`、1600x900）。

## 結果

- 借り物なしで起動し、街・道路・バス停・荷役所・車庫・炭鉱・発電所・線路・駅・線路の車庫が置けた。`command_x` の戻り値は、バス停の 60・61・100 を除き、どれも `null`（成功）。本体は最後まで止まらなかった。
- **バスが旅客を運んで収入が出た**: 2 つのバス停の間を往復し、25 回の読みのうち 12 回で収入が 0 でなかった（2〜5）（`rev` は月ごとの値で単位は未確認）。
- **石炭のトラックが石炭を運んで収入が出た**: 炭鉱の荷役所で積み、発電所の荷役所で降ろした（25 回の読みのうち 10 回で収入が 0 でなかった）。編成一覧の収益は +275.19$（バスは −786.96$）。
- **気動車 + 付随車が、2 つの駅の間を往復して旅客を運び、収入が出た**: 25 回の読みのうち 6 回で、気動車の収入が 0 でなかった（3〜22）。位置は 46〜94 の間を往復した。2 両の継ぎ目に、すき間も重なりも見えなかった（`3_rail_train_94_110.png`）。駅（3 タイル）に停まった（`3_rail_train_94_110.png`・`4_rail_stationA_47_110.png`）。編成一覧の収益は −8,368.12$ で、**旅客の収入が運行費と維持費に届かない**（街の人口を足したのに赤字。つり合いは未調整）。
- 財務の窓（`7_finances.png`。1937 年 9 月 1 日）: 輸送した旅客 50 人（前年 60）、貨物 210（前年 280）。収入は旅客 65.48$（前年 84.88$。**バスと列車の合計**で、列車の分は分けて読んでいない）、貨物 447.99$（前年 597.32$）。運行費 −9,388.38$、維持費 −11,826.00$、運用利益 −20,700.91$（前年 −29,040.27$）。**全体は赤字**。プレイヤーの所持金は −1.5 億$ の保存データ（窓に「破産しました」）なので、黒字・赤字の表示は参考値。

## 確かめていないこと

- 本家 125.0.1（OTRP v64 の Windows だけ）。
- 起動のログの `ERROR`・`Warning`（読んでいない）。zip 内の `LICENSE.md`・`CREDITS.md` の中身。zip を本体の pak のフォルダへ置いた形での起動（作業フォルダの `pak/` に取り出して `-objects pak/` で起動した）。
- 信号が無い（入っていない）ので、複数の編成が同じ線路で行き違う確かめはしていない（編成は 1 つだけ）。
- **α0.2 の保存データを今の pak で読んだときの動き**（仮の道路の車庫を消した。[stations.md](../stations.md) の「保存データへの影響」は、本体のコードの読みで、置いて確かめていない）。説明には引き継げないと書く。
- 新しい地図の作成画面で街・木・炭鉱が出ること（起動画面の間は MCP が答えない）。
- バスだけでの街の成長、人口 650 より先と住宅の段の上がり方（#30）。
- 線路の曲がり・斜め・坂、分岐、3 両以上の編成、逆向き運転。駅の向きは東西だけ。
- ツールバーから実際に線路・駅・車庫・車両を買って置く操作（スクリプトの `append_vehicle` と `command_x` だけ）。
- 運賃・運行費・維持費・旅客の量のつり合い（バス・列車とも赤字）。
- 右側通行の地図、雪などの温帯以外の気候、夜、年代設定が有効な状態。
- 郵便のトラック（走らせていない）。
- 駅は仮の絵（箱を数式で描いた物）。AMI の駅が出たら置き換える（128na/simutrans-addon-dev#264）。
