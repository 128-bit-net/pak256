# 煙

工場の煙突と、ディーゼルの車両・船の煙（本体の `obj=smoke`）の決め事。[#174](https://github.com/128-bit-net/pak256/issues/174) で足した。絵は仮（丸い粒を重ねた物）で、pak128 の絵は使っていない。ゲームでの確かめは [記録](records/2026-11-27_smoke.md)。本体の動きは OTRP の fork の `obj/wolke.cc`・`simfab.cc`・`vehicle/simvehicle.cc`・`simconvoi.cc`・`descriptor/writer/factory_writer.cc` を読んで確かめた（2026-11-27）。

置き場は `objects/smoke/`。`draw_smoke.py`（MIT）が PNG と `smoke.dat` を書き出す。直すときはスクリプトを直して流し直す（`python -X utf8 objects/smoke/draw_smoke.py`。Pillow が要る）。

## 煙の物

| 名前 | 使う物 | 色 | コマ | 粒の半径（最初 → 最後） |
|---|---|---|---|---|
| `pak256_smoke_chimney` | 石炭火力の発電所 | 明るめの灰色 | 6 | 13 → 37px |
| `pak256_smoke_diesel` | 気動車（`pak256_railcar`） | 濃い灰色 | 5 | 8 → 22px |
| `pak256_smoke_ship` | 旅客船・貨物船 | 濃い灰色 | 5 | 10 → 28px |

- 本体は、コマ（`image[0]` から）を寿命の間に順に出し、少しずつ昇らせて左へ流す。絵に向き（`image[向き]`）は無い。
- 付ける側は、dat の `smoke` に煙の物の `name` を書き、煙を引く物と一緒に配る。makeobj の本体の書き方では、産業は煙の物を必須の参照、車両は必須でない参照にしている（`factory_writer.cc`・`vehicle_writer.cc` の `xref_writer_t` の最後の引数）。煙の物が無いときに本体がどうなるかは、どちらも確かめていない。
- 煙の名前は画面に出ないので、訳（`text/`）は置かない。そのため表（`.yaml`）でなく dat を書き出す（`tools/test_text.py` は表の `name` を数える）。
- 色は 3 色を「32 の倍数 + 6」にそろえた。makeobj は半透明の画素の色を赤 3・緑 4・青 3 ビットに落とすので（`descriptor/writer/image_writer.cc` の `pixrgb_to_pixval`）、そうしないと灰色が緑や紫に寄る。

## 工場の煙の付け方

dat のキー（値は [industry.md](industry.md) の発電所）:

| キー | 意味 |
|---|---|
| `smoke` | 煙の物の `name` |
| `smoketile[0]` | 煙を出すタイル（産業の中の x,y） |
| `smokeoffset[0]` | タイルのセルの左上から、煙の絵の左上をずらす量。単位はタイル幅の 1/64（256 のタイルで 4px）。x は −128〜127 |
| `smokeuplift` | 昇る速さ |
| `smokelifetime` | 寿命（ミリ秒）。2497 は車両の排気の印なので使わない |

- 位置は、煙突の口の画面の座標から `draw_industry.py` の `smoke_place()` が出す（煙の絵の粒の中心 (128, 128) を、口の 10px 上に合わせる）。煙突を動かしたら流し直す。
- 添字の無い `smoketile`・`smokeoffset` は古い形で、本体が y を 8 単位ずらすので使わない。
- 煙は、産業が実際に生産・消費した回にだけ出る。石炭が届かない発電所は煙を出さない。出る間隔は、確かめた場面で 10 秒前後（速さ 1。目分量）。
- 煙を付けられるのは産業（`obj=factory`）。街の建物（`obj=building`）には煙のキーが無いので、街の工場 `pak256_factory` の煙突からは出せない。炭鉱には煙突が無いので付けていない。

## 車両と船の煙の付け方

dat のキーは `smoke`（煙の物の `name`）だけ。**位置のキーは無い。**

- 煙は車両の基準点の 32px 上に出る（256 のタイル）。pak256 の車両と船は基準点が車体の前の端なので、**煙は車体・船体の前の端の上に出る**。船は煙突（船首から 20〜33m 後ろ）の位置からは出ない。走り出した船が煙の下を通るので、煙は後ろへたなびいて見える。
- 高さは、煙の絵の粒の中心を、セルの (128, 192) から上げて合わせる（`draw_smoke.py` の `center`）。前後・左右は合わせられない（絵が向きを持たないため）。
- `engine_type` が `steam` でない車両は、**速さが制限の 7/8 より低い間**だけ、0.5 秒ごとに出す（発車の加速のほか、減速などで遅い間も当たる）。確かめた画面では、船は発車のたびに数個だった（目分量）。
- 付けているのは、気動車（動力車だけ）と旅客船・貨物船。モノレールは `engine_type: diesel` だが、電化しなくても走らせるための代わりなので付けていない。路面電車は `electric`。道路の車両（バス・トラック）にも付けていない。

## 確かめていないこと

- 本家 125.0.1、右側通行、地図の回転。
- 海の船は旅客船の昼の発車だけ（貨物船は運河で見た）。船の雪は旅客船だけ。
- 蒸気の車両（pak256 にまだ無い）。
