# 仮の停留所（バス停・荷役所）

バス（[#41](https://github.com/128-bit-net/pak256/issues/41)）とトラック（[#42](https://github.com/128-bit-net/pak256/issues/42)）が客と荷を積み降ろしできるように、道路の上の停留所を pak256 に仮に置いた（[#44](https://github.com/128-bit-net/pak256/issues/44)）。AMI の 256 版の停留所はまだ無く、作るのは先になる（128na/simutrans-addon-dev#264）。**AMI の物が出たら、ここの物は置き換えて消す。** 絵は仮（箱を数式で描いた物）で、pak128 の絵は使っていない。ゲームでの確かめは [記録](records/2026-11-25_road-stops.md)。

置き場は `objects/station/road_stops/`。`draw_stops.py`（MIT）が PNG と表（`.yaml`）を書き出す。直すときはスクリプトを直して流し直す（`python -X utf8 objects/station/road_stops/draw_stops.py`。Pillow が要る）。

## 控え（置き換えのため）

| `name` | `obj` | `type` | `waytype` | 扱う貨物 | 画面の名前（ja / en） |
|---|---|---|---|---|---|
| `pak256_bus_stop` | `building` | `stop` | `road` | 旅客（`enables_pax`）・郵便（`enables_post`） | バス停 / Bus Stop |
| `pak256_truck_stop` | `building` | `stop` | `road` | 貨物（`enables_ware`。旅客・郵便は扱わない） | トラックの荷役所 / Truck Loading Bay |

- どちらも 1x1 タイル、`level` 2（容量。本体は level × 32。値は仮で、pak128 の荷役所に合わせた）、登場年 1900（仮）、`allow_underground` 2、`noinfo` 1。
- AMI の物に置き換えるときは、次を行う。`objects/station/` を消す・`tools/test_stations.py` を消す・`text/` の 2 行ずつ（ja・en）を消す・`CREDITS.md` の行を消す・この文書を消す・`layout.md` の物の種類の表の `objects/station/` の行、道具の表の `test_stations.py` の行、「例外は…」の文を消す。AMI の物の名前は AMI の側（`ja_ami.tab` など）が持つ。
- 保存データは物の名前で引くので、置き換えると、置いてあった停留所は消える（本体は見つからない物を外す）。置き換えは、遊べる版（α0.2）より前に行うのがよい（保存データでの挙動は本体のコードの読みで、置いて確かめてはいない）。

## 向きの絵

停留所の dat は、向きに応じて 8 通りの絵を持つ（本体の決まり。`dims` の 3 つめが 8）。「端」は道路の行き止まりでなく、並んだ停留所の連なりの端で、1 つだけ置くと両端（6・7）の絵が出る（ゲームで確かめた）。端の絵は、帯の端に小さな縁を置くだけで、道路はふさがない。

| 番号 | 向き |
|---|---|
| 0 | NS（左下〜右上の向き）の中ほど |
| 1 | EW（右下〜左上の向き）の中ほど |
| 2 | NS の南端 |
| 3 | EW の東端 |
| 4 | NS の北端 |
| 5 | EW の西端 |
| 6 | NS の両端（単独の停留所） |
| 7 | EW の両端（単独の停留所） |

- 絵は後ろ（車の下）と前（車の上）に分ける。シートは 8 列（向き）× 3 行（0 行 = 後ろ、1 行 = 前、2 行 = 道具の絵）。セルの名前は `<名前>.<行>.<列>`。
- 道路そのものは描かない（道路は AMI が持つ）。道路はタイルの中央を通ると見て、見える側（右下か左下）の脇に歩道（バス停）か積み降ろし場（荷役所。高さ 1m）を置いた。
- 道具の絵（`icon`）は、向き 0 の後ろと前を重ねた 256px のセル（GUI のアイコンは 128px の元を縮める決まり（[gui.md](gui.md)）なので、縮めたときの見え方は未確認の仮）。`cursor` は書かない（置くときのカーソルが出るかは未確認）。

# 仮の道路の車庫

道路の車両（バス・トラック）を買う車庫が、pak256 にも AMI の 256 版にも無かったので、仮の道路の車庫を pak256 に置いた（[#58](https://github.com/128-bit-net/pak256/issues/58)）。AMI の 256 版の車庫は 128na/simutrans-addon-dev#261 の D（線路の後）で、時期は決まっていない。**AMI の物が出たら、ここの物は置き換えて消す。** 絵は仮（箱と屋根を数式で描いた物）で、pak128 の絵は使っていない。ゲームでの確かめは [記録](records/2026-11-25_road-depot.md)。

置き場は `objects/depot/road_depot/`。`draw_depot.py`（MIT）が PNG と表（`.yaml`）を書き出す（`python -X utf8 objects/depot/road_depot/draw_depot.py`。Pillow が要る）。

## 控え（置き換えのため）

| `name` | `obj` | `type` | `waytype` | 画面の名前（ja / en） |
|---|---|---|---|---|
| `pak256_road_depot` | `building` | `depot` | `road` | 道路の車庫 / Road Depot |

- 1x1 タイル（`dims=1,1,4`。向き 4 通り）、登場年 1900（仮）、`noinfo` 1。大きさは concept の C（1 タイル = 26.4m）に合わせ、足跡はタイルの余白 0.12 を残した約 20m 四方、壁 4.6m・棟 6.6m。
- 向きの絵は、戸（車の出入り口）が道路の側を向く。向き 0 = 道路が南西、1 = 南東（どちらも戸が見える面）。2 = 北東、3 = 北西は戸が隠れる面で、地面の舗装（後ろの絵）だけが入口を示す。0・1 は道路の袋小路の端に置いて、戸が道路を向くことを確かめた。2・3 は、4 方向の袋小路に置いたとき建物が道路を向いて置かれることまでは見たが、隠れた面の戸は画面で確かめていない。
- 置き換えるときは、`objects/depot/` を消す・`tools/test_depot.py` を消す・`text/` の 2 行ずつ（ja・en）を消す・`CREDITS.md` の行を消す・この節を消す・`layout.md` の物の種類の表の `objects/depot/` の行、道具の表の `test_depot.py` の行、「例外は…」の文の車庫の部分を消し、`roadmap.md`（例外の一覧と表の車庫の注記）・`vehicles.md` の「車庫は pak256 の仮の物」と試験の節・`tools/vehicle_check/run.py` の説明を AMI の車庫に合わせて直す。車庫に入っていた編成が、定義の消えた車庫の保存データでどうなるかは、本体のコードを読んでおらず未確認（置き換えは配布の前に行い、遊ぶ人の保存データには出さない）。保存データは物の名前で引くので、置き換えると置いてあった車庫は消える（本体のコードの読みで、置いて確かめてはいない）。置き換えは α0.2 より前に行うのがよい。
- 置くときのカーソル（`cursor`）は、道具の絵と同じ絵を 2 行 1 列に置いた。ツールバーから置く操作とカーソルの出方は、ゲームで確かめていない（スクリプトの `build_depot` で置いた）。
- 置いた直後は、本体が建設中の絵（黄黒の縞。`objects/gui/construction`）を出す。ゲームを進める（`debug.set_game_speed(64)` で約 12 秒）と、車庫の絵になる。確認のときに待つ。
