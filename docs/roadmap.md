# ロードマップ（大まか）

2026-11-24 に立てた。決めたことは [concept.md](concept.md)。この文書は道筋で、作業の単位は issue に起こす。段階 0 と 1 は、同じ名前のマイルストーン（「段階 0 土台」#1〜#4、「α0.1 起動できる」#5〜#11）に起こした。

## 進め方（2026-11-24、ユーザー）

- 完璧を目指さず、まず動く状態にしてアルファ版を出す。その後は週に 1 回くらい、小さく出して活動を見せながら進める。
- まずは 1 人で進める。複数人で進捗を合わせる仕組みは、メンバーが増えたときに考える。
- インフラ（線路・道路・橋・トンネル・車庫・架線・駅・停留所・信号・空港と港の道・電線）は AMI に任せる。AMI の 256 対応は [128na/simutrans-addon-dev#261](https://github.com/128na/simutrans-addon-dev/issues/261)、駅・信号などを AMI の範囲に入れるのは [#264](https://github.com/128na/simutrans-addon-dev/issues/264)。
- AMI の 256 版は pak256 の配布に同梱する（2026-11-24、ユーザー）。道路が 1 つも無いと本体が起動しないので、pak256 だけで遊べるようにする。AMI は CC BY 4.0 なので入れられる。帰属は配布の文書に書く。

### 本体が必ず求める物（OTRP の fork のコードで確かめた。2026-11-24）

無いと起動しない、または遊べない物。名前は dat の `name=`。

- 貨物: `Passagiere`・`Post`・`None`（`bauer/goods_manager.cc` の 32 行）。
- 地面: `Shore`・`ClimateTexture`・`LightTexture`・`ShoreTrans`・`SlopeTrans`・`Basement`・`Slopes`・`Fence`・`Marker`・`Borders`・`Water`・`Outside`（`descriptor/ground_desc.cc` の 357 行）。
- GUI: `simskin.cc` の 89〜166 行の、その他（`RibiArrow`・`Construction`・`Sidewalk`・`TunnelTexture` など）・メニュー（`GeneralTools`・`SimpleTools`・`DialogeTools`・`BarTools` など）・記号（`Seasons`・`Passagiere`・`Post`・`Waren` など）・カーソル（`Builder`・`GeneralTools`・`Marked`）。`BigLogo`・`Mouse`・駅の種類の記号などは無くてもよい（同じファイルの「fakultative」）。
- 道路が 1 つ以上（`bauer/wegbauer.cc` の 103 行）。`cityrules.tab`（`simcity.cc` の 301 行）。
- 本家 125.0.1 でも同じかは確かめていない。

## 段階

時期は 1 人で進める前提の目安。週に 1 回出すので、段階の中でも出来た物から出す。

### 0. 土台（1〜2 週）

- リポジトリの形を決める（物の種類ごとのフォルダ、表から dat を作る形、Blender の元データの置き場）。
- CI で makeobj を回して pak を作り、配布の zip を作る。タグを打つと GitHub の Release に上がる形にする。
- 設定ファイル 4 つを pak128 を元に作る（256 に合わせて直す所を洗い出す）。
- 貨物の dat（必須の 3 つ + 最初の産業の分）。

### 1. 起動できる（α0.1、2〜3 週）

本体が必ず求める物をすべて自前の絵でそろえ、地図を作って街が建つところまで。絵は仮でよい。

- 地面一式（温帯だけ。雪・ほかの気候は後で）、水、坂。
- GUI の記号・カーソル・ツールバーのアイコン（`menuconf.tab` で並べる）。
- 道路 1 種（AMI の 256 版。#261 が先に要る）。
- 役場と住宅を数軒。木を 2〜3 種。
- 日本語・英語の訳。

### 2. 遊べる（α0.2、3〜4 週）

旅客と貨物を運んでお金が回るところまで。ここをアルファ版として広く知らせる。

- 線路・車庫・架線・駅とバス停・信号 1 種（AMI。駅と信号は #264 が先に要る）。
- 車両: 旅客の列車 1〜2 編成、郵便・貨物の車両、バス、トラック。ここで concept の C（長さの換算）と D（描画位置の数値）を決める。
- 産業 1 本の連鎖（例: 炭鉱 → 発電所）。
- 住宅・商業・工業の建物を、`cityrules.tab` の段ごとに数軒。

### 3. 広げる（α0.3〜、毎週）

毎週 1〜2 つずつ足す。順番は遊んだ感触で決める。

- 気候（雪・砂漠など）と季節の絵。
- 産業の連鎖を増やす（pak128 の 7 分類に沿って）。
- 車両の顔ぶれと時代（登場年・引退年）。
- 路面電車・船と港・飛行機と空港・モノレール。
- 歩行者・街の車・煙・音。
- 街の建物の数。

### 4. ベータ

- pak128 から移る人が困らない範囲（貨物の連鎖・車両の時代の幅・街の育ち方）がそろう。
- 値（費用・速さ・運賃）の釣り合いをそろえる。
- 本家 125.0.1 で動くことを確かめる（concept の F）。

## 毎週の出し方

- タグ（`v0.1.0` など）を打つと、CI が pak を作って Release に上げる。
- Release の説明に、足した物・変えた物と、画面の写真を付ける。
- 知らせる場所は決めていない。

## 決めていないこと

- ツールバーのアイコンの大きさ（pak128 と同じ 32px か、大きくするか）。段階 1 で GUI を作るときに決める。
- 毎週の知らせ先。最初のアルファ（α0.2）を出す前に決める。
