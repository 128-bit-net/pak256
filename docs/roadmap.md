# ロードマップ（大まか）

2026-11-24 に立てた。決めたことは [concept.md](concept.md)。この文書は道筋で、作業の単位は issue に起こす。段階 0 と 1 は、同じ名前のマイルストーン（「段階 0 土台」#1〜#4・#12・#17、「α0.1 起動できる」#5〜#11）に起こした。段階 0・1 は済んだ（v0.1.0 を 2026-11-25 に公開し、2 つのマイルストーンを閉じた）。段階 2 はマイルストーン「α0.2 遊べる」に起こし、v0.2.0 を 2026-11-25 に公開して閉じた。段階 3 はマイルストーン「α0.3 広げる」から起こしている（その後の版はマイルストーンと [Releases](https://github.com/128-bit-net/pak256/releases) を見る）。

## 進め方（2026-11-24、ユーザー）

- 完璧を目指さず、まず動く状態にしてアルファ版を出す。その後は週に 1 回くらい、小さく出して活動を見せながら進める。
- まずは 1 人で進める。複数人で進捗を合わせる仕組みは、メンバーが増えたときに考える。
- pak256 は、ゲームとして成り立つよう基本的なアドオンを一通り自分で作る。十分な絵を作り込む知見がまだ無いので、当面は動くことを優先する。AMI は景観に寄せたアドオンで方向が違い、今は車両の見た目などを確かめるために間借りしているだけ。pak256 の規格（[standards.md](standards.md)）ができたら、道路・線路なども pak256 専用のアドオンとして作る（2026-11-26、ユーザー。AMI のセッションで）。
- 当面は、今入っている AMI の道路・線路・車庫を使い、AMI に無い物（駅・信号など）は pak256 で簡単な絵で作る（停留所は後で pak256 の物に戻した。#94）。AMI の 256 の見た目の直しは #76・#81 までにする（2026-11-26、ユーザー）。
- AMI はインフラと景観のアドオンで、細かい装飾は基本的なゲームの範囲を超えるので、pak セットの土台にそのまま使うのには向かない。pak256 の開発が熟したら、AMI を 256 にも対応した景観アドオンにすることは考える余地がある。今はそれぞれのマイルストーンを進め、大きさの決まり・道具・作業の知見は AMI と共有しながら進める（2026-11-26、ユーザー。取り決めは親フォルダの手順書 pm.md の「進捗管理が 2 つ並ぶとき」）。
- （2026-11-26 の決定より前の記録）インフラ（線路・道路・橋・トンネル・車庫・架線・駅・停留所・信号・空港と港の道・電線）は AMI に任せる（#46 の駅だけは仮に pak256 で作る。道路の車庫は #64、バス停と荷役所は #72 で AMI の物にした。#94 で pak256 の物に戻した）。AMI の 256 対応は [128na/simutrans-addon-dev#261](https://github.com/128na/simutrans-addon-dev/issues/261)、駅・信号などを AMI の範囲に入れるのは [#264](https://github.com/128na/simutrans-addon-dev/issues/264)。
- AMI の 256 版は pak256 の配布に同梱する（2026-11-24、ユーザー）。道路が 1 つも無いと本体が起動しないので、pak256 だけで遊べるようにする。AMI は CC BY 4.0 なので入れられる。帰属は配布の文書に書く。
- AMI は 128 用で、256 は本来 AMI の範囲外。256 の見た目の直し（道路の路面の粗さなど。[#81](https://github.com/128-bit-net/pak256/issues/81)）は pak256 で引き受け、128 の絵に影響するものだけ AMI の側で合わせる（2026-11-25、ユーザー）。

### 本体が必ず求める物（OTRP の fork のコードで確かめた。2026-11-24）

無いと起動しない、または遊べない物。名前は dat の `name=`。

- 貨物: `Passagiere`・`Post`・`None`（`bauer/goods_manager.cc` の 32 行）。
- 地面: `ClimateTexture`・`LightTexture`・`ShoreTrans`・`SlopeTrans`・`Basement`・`Slopes`・`Fence`・`Marker`・`Borders`・`Water`・`Outside`（`descriptor/ground_desc.cc` の 357 行）。海岸の絵 `Shore` は、無くても動くので作っていない（[ground.md](ground.md)）。
- GUI: `simskin.cc` の 89〜166 行の、その他（`RibiArrow`・`Construction`・`Sidewalk`・`TunnelTexture` など）・メニュー（`GeneralTools`・`SimpleTools`・`DialogeTools`・`BarTools` など）・記号（`Seasons`・`Passagiere`・`Post`・`Waren` など）・カーソル（`Builder`・`GeneralTools`・`Marked`）。`BigLogo`・`Mouse`・駅の種類の記号などは無くても起動する（同じファイルの「fakultative」）。ただし駅の種類の記号が無いと駅・車庫の窓を開くと落ちるので置いた（[gui.md](gui.md)）。
- 道路が 1 つ以上（`bauer/wegbauer.cc` の 103 行）。`cityrules.tab`（`simcity.cc` の 301 行）。
- 本家 125.0.1 でも同じかは確かめていない。

## 段階

時期は 1 人で進める前提の目安。週に 1 回出すので、段階の中でも出来た物から出す。

### 0. 土台（1〜2 週。済み）

- リポジトリの形を決める（物の種類ごとのフォルダ、表から dat を作る形、Blender の元データの置き場）。
- CI で makeobj を回して pak を作り、配布の zip を作る。タグを打つと GitHub の Release に上がる形にする。
- 設定ファイル 4 つを pak128 を元に作る（256 に合わせて直す所を洗い出す）。
- 貨物の dat（必須の 3 つ + 最初の産業の分）。

### 1. 起動できる（α0.1、2〜3 週。済み）

本体が必ず求める物をすべて自前の絵でそろえ、地図を作って街が建つところまで。絵は仮でよい。

- 地面一式（温帯だけ。雪・ほかの気候は後で）、水、坂。
- GUI の記号・カーソル・ツールバーのアイコン（`menuconf.tab` で並べる）。アイコンの大きさは `icon_height` 48 に決めた（[gui.md](gui.md)、#6）。
- 道路 1 種（AMI の 256 版。`ami-256-alpha.1` で同梱し、#64 で `ami-256-alpha.2`（線路・車庫などの 7 つの pak）に上げた）。
- 役場と住宅を数軒。木を 2〜3 種。
- 日本語・英語の訳。

### 2. 遊べる（α0.2、3〜4 週）

旅客と貨物を運んでお金が回るところまで。ここをアルファ版として広く知らせる。

**道路から先に回す**（2026-11-25、ユーザーの決定）。AMI の駅・信号（[#264](https://github.com/128na/simutrans-addon-dev/issues/264)）は AMI の第 5 弾の見込みで、待つと進まないため。バスとトラックなら、道路（済み）・仮のバス停と荷役所・車両・産業で、旅客と貨物を運んでお金が回る。順は次のとおり。

1. [#40](https://github.com/128-bit-net/pak256/issues/40) 車両の長さと描画位置の決まり（済み。[vehicles.md](vehicles.md)）
2. [#43](https://github.com/128-bit-net/pak256/issues/43) 産業 1 本の連鎖（炭鉱 → 発電所。済み）
3. [#44](https://github.com/128-bit-net/pak256/issues/44) 仮のバス停と荷役所。AMI の第 5 弾の 256 版が出るまで pak256 で仮に作り、[#72](https://github.com/128-bit-net/pak256/issues/72) で AMI の物に置き換えた（済み）。
4. [#41](https://github.com/128-bit-net/pak256/issues/41) バスと郵便の車両、[#42](https://github.com/128-bit-net/pak256/issues/42) 石炭のトラック
5. [#30](https://github.com/128-bit-net/pak256/issues/30) 街の成長（旅客を運んで街が育つことを確かめる。住宅の段ごとの数軒は #8 で済み。商業・工業の建物は α0.2 では作らない）
6. [#45](https://github.com/128-bit-net/pak256/issues/45) α0.2 を出す。線路側の [#46](https://github.com/128-bit-net/pak256/issues/46) を待たない。

線路・車庫・列車は [#46](https://github.com/128-bit-net/pak256/issues/46) に起こした。AMI の 256 版（[#261](https://github.com/128na/simutrans-addon-dev/issues/261) の C（線路）・D（車庫））が出るのを待つ。α0.2 に間に合えば入れ、間に合わなければ次（α0.3）に回す。駅・信号は AMI の第 5 弾（#264）の見込みだった（2026-11-26 に AMI は作らないことになり、pak256 の物にした。#73）。#46 で、線路・車庫は AMI の `ami-256-alpha.2`、駅は仮に pak256 で作り、信号は入れずに進めた。

- 車両: バス・トラックを先に。旅客と郵便・貨物の列車は、線路が来てから 1〜2 編成。concept の C（長さの換算）と D（描画位置の数値）は #40 で決めた。
- 線路・車庫・架線: AMI。駅・信号 1 種: pak256（#73。2026-11-26 に AMI から変えた）。

### 4. ベータ

- pak128 から移る人が困らない範囲（貨物の連鎖・車両の時代の幅・街の育ち方）がそろう。
- 値（費用・速さ・運賃）の釣り合いをそろえる。
- 本家 125.0.1 で動くことを確かめる（concept の F）。

## 毎週の出し方

- タグ（`v0.1.0` など）を打つと、CI が pak を作って Release に上げる。
- Release の説明に、足した物・変えた物と、画面の写真を付ける。
- 知らせるのは、線路と道路が入ったとき（Discord など）から。それまでは private のリポジトリの Release に出すだけ（2026-11-25、ユーザー）。

## 決めていないこと

- 線路と道路が入ったときの、知らせる場所と文面。
