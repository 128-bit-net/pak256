# 線路の信号（pak256 の物）

線路の信号は、閉塞信号を 1 種だけ pak256 で作った（[#73](https://github.com/128-bit-net/pak256/issues/73)。2026-11-26、ユーザーの決定: pak256 は基本のアドオンを自分で作り、当面は絵より動くことを優先する。[roadmap.md](roadmap.md) の「進め方」）。AMI は信号を作らず、AMI の `ami_rail_signal` は使わない。絵は簡単な物（箱を数式で描いた物）で、pak128 の絵は使っていない。

置き場は `objects/signal/rail_signal/`。`draw_signal.py`（MIT）が PNG（`rail_signal.png`）と表（`rail_signal.yaml`）を書き出す。直すときはスクリプトを直して流し直す（`python -X utf8 objects/signal/rail_signal/draw_signal.py`。Pillow が要る）。

| `name` | `obj` | `waytype` | 種類 | 画面の名前（ja / en） |
|---|---|---|---|---|
| `pak256_rail_signal` | `roadsign` | `track` | 閉塞信号（`is_signal=1`） | 信号 / Signal |

- 閉塞信号: ふだんは赤で、列車が近づいて次の区間（次の信号までの線路）が空いているときだけ青にして通す（本体の動き）。登場年 1900、建設費 `cost=500`（値は仮。`simuconf.tab` の `cost_signal` は別の値）。
- **絵の並び**: dat の `image[i]` の `i` は 状態 × 4 + 向き。向きは 0 = n（北へ進む列車用）、1 = s、2 = w、3 = e（本体の `signal_t::calc_image` の添字の順。数字の書き方のとき。名前の書き方 `image[e][0]` では e と w が逆）。状態は 0 = 赤、1 = 青。シートは 8 列 × 2 行で、0 行が信号の絵、1 行の 0 列が道具の絵（`icon`。192px の角丸の四角。駅と同じ作り）、1 列がカーソル（`cursor`）。セルは 256px（1 タイル）で、位置合わせは付けない。
- **立てる場所**: 日本の左側通行に合わせ、信号は進む向きの左、タイルの出口の側に立てる（南へ進むなら +u 側・北へなら -u 側、東へなら -v 側・西へなら +v 側）。線路はタイルの中央（c = 0.43〜0.57）を通ると見て、柱は線路の脇（c = 0.30 か 0.68）に立つ。本体の `is_signals_left`（信号を左に立てる設定）の地図では、`offset_left`（既定 14）の分だけ絵がずれて前後も入れ替わるが、絵は最初から左に描いてあるので、`offset_left: 0` にして使わない（読んだだけで、確かめていない）。
- **大きさ**: 実物より少し大きく描いた。柱は高さ 5.0m（幅 0.06 タイル）、頭は高さ 1.6m（幅 0.14 タイル。約 3.7m）。実物（柱と頭で 5m 前後）どおりだと、256px のタイルでは小さすぎて、列車の陰に隠れたため。縮尺は [サイトの縮尺と大きさ](https://128-bit-net.github.io/pak256/spec/scale)（1 単位 = 1.65m）。
- **灯り**: 頭の側面の色（赤か緑）。上面は暗い灰色。
- ツールバー: 線路のツールバー（`toolbar[3]`）の `signs(2)` に並ぶ。信号の撤去は `general_tool[46]`（アイコンはバーの 47 番。赤い地に信号と ×）。設定は [config.md](config.md)。

## 置いたときの動き（OTRP v64 で確かめた）

- 置くと、まず**両方向**の信号になる（2 つの柱が立つ）。同じ所にもう一度置くと、片方向になる。3 回目は反対の片方向、4 回目で両方向に戻る（本体のコードの読み。OTRP の `simtool.cc` の `place_sign_intern`。2 回目までは確かめた）。本体の中では、信号が持つ向きは「通れない向き」の ribi で、東西の線路の 2 回目は東（列車は西へ進む）、南北の線路の 2 回目は北（列車は南へ進む）になる。ゲームで確かめたのは、上の辺（東西）に 2 回置くと列車が西へ進み、左の辺（南北）に 2 回置くと南へ進むこと。画面から置くときも同じ（未確認）。
- 片方向の信号は、逆向きの列車の経路をふさぐ。両方向の信号だけを置いた 1 本の線路（周回）に、逆向きの編成が入ると、向き合って止まる（止まったまま動かなくなった。向き合ったのが原因と見ている。下の記録）。周回させるときは、信号を片方向にそろえる。
- 信号が青になるのは、列車が近づいて通れるときだけ（上に書いた本体の動き）。静止画では赤が多く、青は列車が通る少しの間だけ出る。

## 確かめ

[記録](records/2026-11-26_rail-signal.md)。`tools/vehicle_check/signal.nut`（開いたまま `tools/game.py --send-file` で流す。[game-check.md](game-check.md)）が、周回の線路・駅 2 つ・車庫・信号 4 つ・編成 4 つを置く。

## 確かめていないこと

- 坂・斜め（`diagonal` の絵は付けていない。曲がりの上では直線の絵が出る）・分岐の上の信号。
- 左右の逆側の通行（`is_signals_left`）、夜の見え方、本家 125.0.1。
- 画面からの置き方（ツールバーのボタンを押して置く操作）。スクリプトの `build_sign_at` で置いた。ボタンの絵と並びは画面で見た。
- 信号の撤去の道具の動き（ボタンの絵だけ見た）。
- 複数の信号の種類（先行信号・長閉塞・優先など）。作っていない。
