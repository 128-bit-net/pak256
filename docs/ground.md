# 地面の描き方

地面一式（`objects/ground/`）の決め事。256px のタイルで、本体（OTRP）が地面をどう読むかをまとめた。[#5](https://github.com/128-bit-net/pak256/issues/5) で描いた。絵は仮（数式で描いた物）で、見た目は後から描き直す。

本体の読み方は `simutrans/descriptor/ground_desc.cc`・`simutrans/boden/grund.cc`、並べ方の見本は、作業場の参照用の pak128（リポジトリの外。`landscape/grounds`）で確かめた。pak128 の絵は写していない（並べ方の決まりだけを読んだ）。

## 置き場と作り方

| 場所 | 中身 |
|---|---|
| `objects/ground/Outside/` | 地図の外のタイル 1 枚だけ。本体は `ground.Outside.pak` というファイルを先に探してタイルの幅を決めるので、別のフォルダにしてある（フォルダ名の大文字小文字もそのまま pak の名前になる） |
| `objects/ground/temperate/` | それ以外の地面。`draw_ground.py`（元・MIT）が絵（PNG のシート）と dat を書き出す。書き出した物もコミットしてある |

作り直すとき: `python -X utf8 objects/ground/temperate/draw_ground.py`（Pillow だけで動く。1 分ほど）。組むのは `python -X utf8 tools/build.py`。

## タイルの寸法

- マスは 256x256。平らなタイルの菱形は、行 129〜255 の 127 行で、行 `128+k` の幅が `4k`（k ≤ 64）、その下は `4(256-k')` と細くなる。幅 256 になるのは行 192 だけ。
- 本体はこの幅（`Outside` の絵の幅）をタイルの幅にする。ClimateTexture の幅と同じでないと止まる。
- 高さ 1 段 = 32px。pak の `config/simuconf.tab` に `tile_height = 8` が要る（本体の既定は 16 で、無いと 1 段が 64px になり、壁・坂・つなぎ目がずれる）。リポジトリの `config/simuconf.tab`（[#3](https://github.com/128-bit-net/pak256/issues/3)、[config.md](config.md)）に `tile_height = 8` が入っている。#3 より前の確認は、pak の隣に同じ内容を手で置いて行った。四隅の高さ（0〜2 段）で、角の位置が `南西 y=192-32h`、`南東 y=256-32h`、`北東 y=192-32h`、`北西 y=128-32h` に動く。
- 地面の絵は、列ごとに「上の辺 ≤ 行 < 下の辺」の画素を塗る。隣のタイルと隙間も重なりも出ない（辺の上の画素は上のタイルが持つ）。

## 枠の線（印・格子の線・カーソル）

`Marker`・`Borders` と、GUI のカーソル（[gui.md](gui.md)）の枠は、`ImageDraw.line` で端の点を結ばず、地面の画素の端から内側へ決めた行数を列ごとに塗る（`draw_ground.py` の `edge_pixels`）。端の点を結ぶと、傾きが割り切れずに階段が崩れ、地面の縁ともずれる（[#112](https://github.com/128-bit-net/pak256/issues/112)）。

- 両端の高さが同じ辺は、横 2px・縦 1px の階段になる。
- 両端の高さが違う辺は、地面の縁と同じ階段（128 列で 0・32・96・128 行の変化。水平・4:1・4:3・1:1）で、2:1 にはならない（1 段 32px のため）。
- 2 列の組がそろうのは等倍の表示だけ。拡大・縮小の段では、本体が絵を拡大・縮小するので階段の刻みは変わる。

## 物ごとの決め事

| Name | 中身 | 並び |
|---|---|---|
| `Outside` | 平らな菱形 1 枚 | `Image[0][0]` |
| `ClimateTexture` | 256x256 の模様 8 枚（0 水・1 砂漠・2 熱帯・3 地中海・4 温帯・5 ツンドラ・6 岩・7 雪）。7 気候を気候ごとの式で描き分けた（[#101](https://github.com/128-bit-net/pak256/issues/101)）: 砂漠は砂丘のさざ波と小石、熱帯は濃い茂みと若葉、地中海は乾いた草と赤茶の土・石灰岩、温帯は草、ツンドラはこけと地衣類・湿った土・残雪、岩は割れ目のある岩盤、雪は吹きだまりの青い影（坂の明るい面が白く飛ばない明るさに抑えた）。0 の水は `Water` が描くので下絵だけ | 透明な画素が無いこと。斜め格子の周期で隣のタイルとつながる |
| `LightTexture` | 坂 81 通りの明るさ。番号 = 南西 + 3 × 南東 + 9 × 北東 + 27 × 北西（各隅 0〜2） | 灰色。平らが 134。特別な色（`0x6B6B6B` など）に当たる値は 1 ずらす |
| `ShoreTrans` | 海岸のつなぎ目 12 枚。赤い所に水が出る。0〜3 が基本の形、11 が全部水 | 正方形。本体が回して使う |
| `SlopeTrans` | 気候・雪線のつなぎ目 15 枚。緑と青の所に重ねる絵が出る（青は 2 段の坂の高い所）。回転 0 の絵の四隅は `draw_ground.py` の `SLOPE_TRANS_CORNERS`（`ground_desc.cc` の case の表）。14 は四隅とも重ねるときで、中央だけ抜く | 正方形 |
| `Water` | 水。深さ 0〜5 の行に、それぞれ動く 8 コマ（本体は深さの行の今のコマを引くので、どの深さも全コマ要る）。深さの最大は 4 なので 5 の行は今は使われない | 平らな菱形。斜め格子の周期 |
| `Slopes` / `Basement` | 壁。左（南西→北西）の 11 枚（番号 0〜10）と奥（北西→北東）の 11 枚（11〜21）。番号 = 始めの高さ + 3 × 終わりの高さ（段）、9・10 は片方が下がる三角 | 壁の絵は 128・64 の周期の模様にして、隣・上下に積んでも継ぎ目が出ない |
| `Fence` | 柵 6 枚。0〜2 が自然（左・奥・両方）、3〜5 が建物 | |
| `Marker` | 地面の印の線。前 27 枚（番号 = 南西 + 3 × 南東 + 9 × 北東）と奥 27 枚（27 + 南西 + 3 × 北東 + 9 × 北西） | |
| `Borders` | 格子の線 27 枚。奥の線（南西→北西→北東）で、番号 = 南西 + 3 × 北東 + 9 × 北西（本体の `get_border_image`） | |

`Shore`（本体が重ねる海岸の絵）は、pak128 にも無く、本体も無くて動く（`ground_desc_t::shore` が空のときは何も重ねない）ので作らなかった。

## 確かめたこと

- `LightTexture` 81 枚・`Slopes`・`Basement` 22 枚の形は、2 倍にした pak128 の同じ番号の絵（比べるためだけに読んだ。コピーしていない）と重なりを比べて、全部が合う。`SlopeTrans`・`ShoreTrans` は重なる領域の向きが合う。
- `Marker`・`Borders` は、下の「枠の線」の決まりで描き、地面の絵と画素単位で一致することを `tools/test_frames.py` が確かめる。`Marker` はゲームで平地・1 段と 2 段の坂の上に出して確かめた（[記録](records/2026-11-26_cursor-frame.md)）。`Borders` は絵の検査だけ。
- ゲームで、平地・単段と複段の坂・海岸・水（動く）・壁・柵・地図の端を確かめ、AMI の 256 版の線路が坂に合うことを見た（`docs/records/2026-11-25_ground-screens/`）。`Basement` は絵の比較だけで、ゲーム内では見ていない。
- 気候の描き分け（#101、`docs/records/2026-11-26_climate-ground-screens/`）: 7 気候の平地の帯・隣り合う 2 気候の境 6 つ・1 段と 2 段の丘の縁（周りは温帯。雪の丘で、雪の気候と温帯の境の坂を見た。気候は `tool_set_climate` で塗ったので、高さで決まる雪線そのものは確かめていない）・湖の海岸（砂漠・温帯・雪・ツンドラ）をゲームで見て、隙間・重なり・継ぎ目のずれが無いことを確かめた。気候の境の坂にはつなぎ目の絵（`SlopeTrans`）が重なり、縁に小さな丸い突起が並ぶのは気候の境（`SlopeTrans` の形）のため。
- 1 枚の絵がタイルごとに繰り返されるので、大きな模様（砂のうねり・土のまだら）は繰り返しが見えやすい。目立つ特徴は細かく・弱くして抑えた。

## 絵を足す・直すとき

- 壁と柵は、地面の高さ 0 の菱形に合わせて描く。本体が段の分だけ上に動かす。
- 絵の色は RGBA で、透明は α = 0。`0xE7FFFF` と、makeobj が特別な色にする物（`draw_ground.py` の `_SPECIAL`）は使わない。
- 斜め格子の周期: ClimateTexture と Water は、`(128,64)` ずらしても `(128,-64)` ずらしても同じ模様になるように描く（隣のタイルとつなげるため）。`draw_ground.py` の `lattice()` と `vnoise()` がその座標。ClimateTexture は `tools/test_ground.py` が、コミットしてある PNG で確かめる（Water は菱形で、ずらした先が重ならないので対象外）。
