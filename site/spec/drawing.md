# 絵の共通の決まり

どの種類の物にも当てはまる決まりです。PNG の中の位置は [タイルとセル](./tile-and-cell.md) を見てください。

## 光と影

- **光は左上から**当てます。左下を向く面を明るく、右下を向く面を暗くします。
- **影は描きません。** 飛行機の飛行中の影は、本体が機体の絵から作ります。

## 描き方

- 元の絵は 2 倍・4 倍などの大きさで描いてから縮めると、縁がなめらかになります。
- PNG は RGBA（または RGB・パレット）にします。グレースケールに透明度を足した形式は、透明度が捨てられます。

## 透明

- pak256 の決まりでは、**半透明の画素を残しません**。縮めて縁をなめらかにした後、透明か不透明のどちらかに切ります。透明はアルファ 0 にします。
- これは pak256 の決まりで、makeobj の制限ではありません。makeobj は次のように読みます。

| PNG の画素 | makeobj の扱い |
|---|---|
| 色が `#E7FFFF` | 完全な透明 |
| アルファ 0〜7 | 完全な透明 |
| アルファ 8〜254 | 半透明のまま保存する |
| アルファ 255 | 不透明。ふつうの色は各色の下位 3 ビットが落ちる |

## 特別な色

次の色は、**1 ビットでも一致すると** makeobj が別の意味に読みます。意味が要らない所には使わないでください（青の値を 1 ずらせば、ふつうの色になります）。

| PNG の色（16 進の RGB） | 意味 |
|---|---|
| `#E7FFFF` | 透明 |
| `#244B67` `#395E7C` `#4C7191` `#6084A7` `#7497BD` `#88ABD3` `#9CBEE9` `#B0D2FF` | 会社の色 1（暗い方から 8 段） |
| `#7B5803` `#8E6F04` `#A18605` `#B49D07` `#C6B408` `#D9CB0A` `#ECE20B` `#FFF90D` | 会社の色 2（暗い方から 8 段） |
| `#57656F` `#7F9BF1` `#C1B1D1` `#4D4D4D` | 夜に灯る窓 |
| `#FFFF53` `#FF211D` `#01DD01` `#FF017F` `#0101FF` `#E3E3FF` | 灯り（黄・赤・緑・紫・青・白） |
| `#6B6B6B` `#9B9B9B` `#B3B3B3` `#C9C9C9` `#DFDFDF` | 夜も暗くならない灰色 |

夜の色は、pak の `simuconf.tab` の `special_color` で変えられるものがあります。

pak256 の物が会社の色や夜の灯りの色を使うかどうかは**未定**です（今の仮の絵は、これらの色を避けて描いています）。

## 冬と雪の絵

絵の枚数と使われ方は、物の種類で違います。

| 種類 | 冬・雪の絵の持ち方 |
|---|---|
| 建物（`building`） | 画像の添字の季節の数で決まる。1 枚は固定。2 枚と 3 枚は雪の所だけ 2 枚目。4 枚は夏・秋・冬・春で、雪の所は冬。5 枚は 5 枚目が雪 |
| 木（`tree`） | `seasons` の数だけ、樹齢ごとに描く |
| 地面の飾り（`ground_obj`） | `seasons` の数だけ描く |
| 道・橋・トンネル | 画像のキーに季節の番号を付ける |
| 車両 | pak256 の車両は冬の絵を持たない |

建物を暦の冬にも雪の絵にするには **4 枚**にします（秋と春は夏と同じ絵を指してよい）。2 枚では、雪の気候と雪線の上でしか使われません。
