# 信号

線路の信号の作り方です。停留所は [駅・停留所](./station.md) を見てください。

## 何が作れるか

`obj=roadsign` で `waytype=track` の、閉塞信号（`is_signal=1`）です。ふだんは赤で、列車が近づいて次の区間（次の信号までの線路）が空いているときだけ青にして通します。

本体には、ほかに `is_presignal`（先行信号）・`is_prioritysignal`（優先信号）・`is_longblocksignal`（長閉塞信号）や、`free_route` の信号があります。pak256 には閉塞信号の 1 種だけがあり、ほかの種類の作り方は**未定**です。道路の標識もこのページでは扱いません。

![線路の脇の信号。列車がいないとき、手前の側の信号の脇を通るとき、奥の側の信号の脇を通るとき](/spec/signal-screen.png)

画面は OTRP の最新版です（2026-11-27、2 倍に拡大）。絵は仮です。線路は pak256 に同梱の AMI（CC BY 4.0、作者 128na）です。

## 大きさと基準点

- 信号の絵は 256 のセル（1 タイル）で、基準点は (128, 192) です（[タイルとセル](./tile-and-cell.md)）。
- pak256 の信号は、**進む向きの左**、タイルの出口の側の端（軸の向きの位置が出口から 0.14 タイル）、線路の脇（軸に直交する位置 c = 0.30 か 0.68）に立てます。線路はタイルの中央（c = 0.43〜0.57）を通ります。左に立てるのは日本の左側通行に合わせるためです。
- 位置 c は、軸に直交する向きで、画面の上の側が 0 です。n・e の信号は奥の側（c = 0.30）、s・w の信号は手前の側（c = 0.68）に立ちます。
- pak256 の信号の高さ（手本の値）は、柱が 5.0m、頭が 1.6m（合わせて約 6.6m）です。実物（5m 前後）より少し大きく描いています。実物どおりでは 256px のタイルで小さすぎ、列車の陰に隠れたためです。

縮尺は [縮尺と大きさ](./scale.md) です。

## 絵

### 向きと状態

1 つの信号は、**列車の進む向き 4 つ × 状態**の絵を持ちます。閉塞信号の状態は赤と青の 2 つで、8 枚です。

![pak256 の信号の 8 枚の絵。矢印は列車の進む向き](/spec/signal-sheet.png)

添字は `状態 × 4 + 向き` です。

| 向き | 進む向き（画面） | 赤の添字 | 青の添字 |
|---|---|---|---|
| n | 右上 | 0 | 4 |
| s | 左下 | 1 | 5 |
| w | 左上 | 2 | 6 |
| e | 右下 | 3 | 7 |

向きの順は **n・s・w・e** です。添字は番号で書きます。

### 手前と奥

本体は、信号が 1 方向だけを向くとき、**n・e の絵を車両の手前に、s・w の絵を車両の奥に**描きます。これは、信号を**進む向きの右**に立てた絵に合う順です（設定 `signal_reverse_front_back` を変えていないとき）。

pak256 の信号は進む向きの左に立てているので、手前と奥が合いません。画面の手前の側に立つ s・w の信号は、列車が脇を通ると列車の陰に隠れます（上の画面の中）。奥の側に立つ n・e の信号は列車より手前に描かれ、土台や柱が列車の屋根に重なります（上の画面の右）。pak256 の信号の描き直しは**未定**です。

信号を左に立てる設定の地図では、`offset_left` が 0 でない信号の絵を本体がずらし、手前と奥の順も変えます。

### 層と季節

- 手前と奥の層は、絵ごとに分けません（上の「手前と奥」のとおり本体が決めます）。
- pak256 の信号は冬の絵を持ちません。
- 曲がりの上では直線の向きの絵が出ます。pak256 は斜めの線路用の絵を付けていません（付け方は**未定**）。

## dat のキー

書き方の共通の決まりは [dat の共通のキー](./dat.md) を見てください。信号で使うキー:

| キー | 内容 |
|---|---|
| `obj` | `roadsign` |
| `waytype` | `track` |
| `is_signal` | 閉塞信号は `1` |
| `image[N]` | 絵。上の添字の順。枚数は 4 の倍数 |
| `offset_left` | 信号を左に立てる設定の地図で、絵をずらす量（px）。省くと 14。pak256 の信号は絵を最初から左に描くので **`0`** にします |
| `cost` | 建設費。省くと 500。値の目安は**未定** |
| `min_speed` | この速さより遅い車両を通さない値（km/h）。省くと 0（制限なし）。信号では確かめていません |
| `intro_year`・`retire_year` | 登場と引退 |
| `icon`・`cursor` | 道具の絵と、置くときのカーソル |

### 例: 閉塞信号

画像 `signal.png` の 0 行目に 8 枚を添字の順で並べ、1 行目の 0 列を道具の絵、1 列をカーソルにする形です。

```
obj=roadsign
name=example_signal
copyright=あなたの名前
waytype=track
is_signal=1
offset_left=0
intro_year=1900
cost=500
icon=> signal.1.0
cursor=signal.1.1
image[0]=signal.0.0
image[1]=signal.0.1
image[2]=signal.0.2
image[3]=signal.0.3
image[4]=signal.0.4
image[5]=signal.0.5
image[6]=signal.0.6
image[7]=signal.0.7
```

## 本体の動きの注意

- **置いた直後は両方向**の信号（柱が 2 本）です。同じ所にもう一度置くと片方向になり、3 回目は反対の片方向、4 回目で両方向に戻ります。
- 片方向の信号は、逆向きの列車の経路をふさぎます。1 本の線路の周回に両方向の信号だけを置くと、逆向きの編成どうしが向き合って止まります。周回させるときは、信号を片方向にそろえます。
- 青になるのは、列車が近づいて通れるときだけです。静止した画面では赤が多く、青は通る少しの間だけ出ます。
- 信号の撤去は線路のツールバーにある、専用の道具です。
- 保存データは信号を `name` で指します。配った後は変えないでください。

## 確かめていないこと

- 本家の Simutrans、信号を左に立てる設定の地図での見え方。
- 上の dat の例をゲームで動かすこと。
- 4 回目の置き直しで両方向に戻ること。
- 進む向きの右に立てた絵の見え方。
- 坂・斜め・分岐の上の信号と、夜の見え方。
- ツールバーのボタンを押して置く操作と、撤去の道具の動き。
- 閉塞信号以外の種類。
