# 船・港

船と、桟橋・岸壁・運河の船着き場の作り方です。川は [川](./river.md)、飛行機は [飛行機・空港](./air.md) です。

## 何が作れるか

| 種類 | `obj` と主なキー | pak256 の今の物 |
|---|---|---|
| 船 | `vehicle`、`waytype=water` | 旅客船、貨物船 |
| 桟橋（水に面した坂に建てる） | `building`、`type=habour` | 桟橋 |
| 岸壁（水に面した平らな土地に建てる） | `building`、`type=dock` | 岸壁 |
| 運河の船着き場（運河の道の上に建てる） | `building`、`type=stop`、`waytype=water` | 運河の船着き場 |

`type=habour` の綴りは本体の書き方のとおりです（`harbour` と直さないでください）。

運河と船の車庫は、pak256 に同梱の AMI（CC BY 4.0、作者 128na）の 256 版を使います。pak256 には自前の運河と車庫がありません。

![海の桟橋と岸壁、旅客船と貨物船の画面](/spec/ship-sea.png)

![AMI の運河の船着き場と旅客船の画面](/spec/ship-canal.png)

画面は OTRP の最新版、等倍です（2026-11-27）。絵はどれも仮です。運河と車庫は同梱の AMI（CC BY 4.0、作者 128na）です。

## 大きさと基準点

### 船の大きさ

船は、道路と線路の車両の「手本の 2 倍」ではなく、**実物の寸法**から決めます（決定: 2026-11-25、大型船は 2026-11-27）。中型船と大型船で縮尺が違います。

| 種類 | 用途と実物の長さ | 描く大きさ | `length` | 例 |
|---|---|---|---|---|
| 中型船 | 運河・内水・近距離の船。**60m 以下** | **実物比例**（長さ・幅・高さとも実物） | 実物の長さ ÷ 1.65 を四捨五入 | 30m → 18、36m → 22 |
| 大型船 | 外洋向けの船。**130m 以上** | 長さ・幅・高さとも**実物の 0.47 倍** | 実物の長さ × 0.47 ÷ 1.65 | 224.5m のフェリー → 約 105m、`length` 64 |

- 中型船を実寸にするのは、256px のタイルで描くと運河向けの中型船らしい大きさになるためです。大型船の 0.47 は、手本（SKS 氏の新日本海フェリーを 2 倍にした版）の長さの実物比です。幅と高さも同じ倍率にして、形を崩さないようにします（[記録](https://github.com/128-bit-net/pak256/blob/main/docs/records/2026-11-27_sks-scale.md)）。
- 60m と 130m の境は仮の値です。60m を超えて 130m 未満の船の倍率は**未定**です。
- 寸法を px にする換算は [縮尺と大きさ](./scale.md) のとおりです。

### 基準点

- 中型船は、**船首の先を基準点に置き、船体を進む向きの後ろへ伸ばします**。
- 船は水路の中心に出ます。横のずれは付けません。
- **喫水線は地面の高さ**（水面）です。
- 30m・36m の船は 256 のセルに収まらないので、**512 のセル**に描きます（`cell_size=512` と、位置合わせ `,-128,-128`。[タイルとセル](./tile-and-cell.md)）。
- 大型船の基準点とセルは**未定**です。

![pak256 の仮の旅客船の 8 方向の絵。十字は基準点で、船体は基準点から後ろへ伸びる](/spec/ship-directions.png)

### 港の大きさ

港は **1×1 タイル**の部品で、基準点は 256 のセルの (128, 192) です。桟橋と岸壁は**水のある側**で向きが決まります。

![桟橋と岸壁の 4 通りの向きの絵。青い線が水のある側の辺](/spec/port-layouts.png)

pak256 の今の港の高さ（手本の値。水面からの高さ）です。

| 物 | 高さ |
|---|---|
| 桟橋の平らな板 | 2.4m。陸の端は、1 段（32px、約 5.4m）高い坂の上の端につなぐ |
| 岸壁の敷き面 | 1m |
| 運河の船着き場の板 | 0.5m |

- **桟橋**は、坂の上の端から板の斜路で下り、水の側は杭の上の平らな板にします。
- **岸壁**は、敷き面と、陸の側の上屋、水の側の係船柱です。
- **運河の船着き場**は、船が通る中ほどを空けて、運河の両脇に板を張ります。pak256 の板は、軸に直交する向きの位置（タイルの幅を 1、画面の上の側が 0）で 0〜0.14 と 0.86〜1 です。pak256 の船の幅 7〜8m は、タイルの 0.27〜0.30 にあたります。

## 絵

### 向き

- **船**は 8 方向の絵を描きます。キーは画面の上で進む向きです（[タイルとセル](./tile-and-cell.md) の「向きの呼び方」）。
- **桟橋・岸壁**は 4 通りです。

| 番号 | 水のある側 |
|---|---|
| 0 | 南（画面の左下） |
| 1 | 東（右下） |
| 2 | 北（右上） |
| 3 | 西（左上） |

- **運河の船着き場**は、[駅・停留所](./station.md) の「絵」と同じ 8 通りです。

### 層と季節

- 船の絵は 1 枚で、手前と奥に分ける層はありません。
- 運河の船着き場は、船の奥の板を `backimage`、手前の板を `frontimage` に描きます。pak256 の桟橋と岸壁は `backimage` だけです。
- pak256 の船と港は冬の絵を持ちません。
- 積み荷の絵は `freightimage` で足せます。pak256 では貨物船だけが持ちます。

## dat のキー

書き方の共通の決まりは [dat の共通のキー](./dat.md) を見てください。

| キー | 内容 |
|---|---|
| `waytype` | 船と運河の船着き場は `water`。桟橋・岸壁には書かない |
| `type` | `habour`（桟橋）・`dock`（岸壁）・`stop`（運河の船着き場） |
| `length`・`cell_size` | 船。上の「船の大きさ」 |
| `emptyimage[向き]`・`freightimage[向き]` | 船の絵 |
| `freight`・`payload` | 船が運ぶ貨物の名前と量 |
| `engine_type`・`speed`・`power`・`gear`・`weight`・`cost`・`runningcost` | 船の性能と費用。値の目安は**未定** |
| `smoke`・`sound` | 煙と発車の音（物があるとき） |
| `enables_pax`・`enables_post`・`enables_ware` | 港で扱う物。`1` で扱う |
| `level` | 港の大きさの元の値 |
| `dims` | `1,1,向きの数`。桟橋・岸壁は 4、運河の船着き場は 8 |
| `backimage[向き][y][x][高さ][コマ]`・`frontimage[…]` | 港の絵 |
| `icon`・`intro_year`・`retire_year`・`noinfo` | [駅・停留所](./station.md) と同じ |

### 例: 旅客船

512 のセルの 8 方向を、1 枚の画像 `ferry.png` の 1 行に並べた形です。性能は例の値です。

```
obj=vehicle
name=example_ferry
copyright=あなたの名前
waytype=water
engine_type=diesel
freight=Passagiere
payload=300
speed=37
power=2400
weight=70
length=18
cell_size=512
emptyimage[s]=ferry.0.0,-128,-128
emptyimage[w]=ferry.0.1,-128,-128
emptyimage[sw]=ferry.0.2,-128,-128
emptyimage[se]=ferry.0.3,-128,-128
emptyimage[n]=ferry.0.4,-128,-128
emptyimage[e]=ferry.0.5,-128,-128
emptyimage[ne]=ferry.0.6,-128,-128
emptyimage[nw]=ferry.0.7,-128,-128
```

### 例: 桟橋

画像 `pier.png` の 0 行目が 4 通りの絵、1 行目の 0 列が道具の絵の形です。岸壁は `type=dock` にします。

```
obj=building
name=example_pier
copyright=あなたの名前
type=habour
enables_pax=1
enables_post=1
enables_ware=1
level=4
intro_year=1900
noinfo=1
dims=1,1,4
icon=> pier.1.0
backimage[0][0][0][0][0]=pier.0.0
backimage[1][0][0][0][0]=pier.0.1
backimage[2][0][0][0][0]=pier.0.2
backimage[3][0][0][0][0]=pier.0.3
```

運河の船着き場は、[駅・停留所の例](./station.md#例-線路の駅) の `waytype=track` を `waytype=water` にした形です。

## 本体の動きの注意

- **建てる所**: 桟橋は、水に面した 1 段の坂で、坂の先が水の所に建てます。岸壁は、水面と同じ高さの平らな土地で、隣が水の所に建てます。運河の船着き場は運河の道の上です。
- **ダイヤの行き先**: 桟橋・岸壁へは、港の升ではなく手前の水面の升を指します（港の升を指すと、スクリプトでは断られました）。
- **旅客**: 停留所の届く範囲（pak256 は 2 タイル）に街の建物が無いと、旅客が来ません。
- **車庫**: 海では、岸に接した水の升に置きます。四方が水の升には建ちません。陸の運河では行き止まりに置きます。海につながる短い運河の行き止まりにも建ちます。
- **左側通行**でも、船は水路の中心に出ます。
- **煙**は船の基準点の 32px 上に出ます。煙突の位置ではなく、船首の上に出ます。
- **大型船**は、絵の端が欠けて見えることがあります（`length` 64 の船）。pak256 はこの欠けを受け入れます（決定: 2026-11-27、[記録](https://github.com/128-bit-net/pak256/blob/main/docs/records/2026-11-27_standards-8-2.md)）。

## 確かめていないこと

- 本家の Simutrans、右側通行の地図、雪の気候。
- 上の dat の例をゲームで動かすこと。
- 岸壁の水が南・東の向き。
- 船の曲がり・斜めの進路・すれ違いの見え方。
- 2 タイル以上の長い桟橋・岸壁と、16 通りの向き。
- 自前の運河と船の車庫の作り方。
- ツールバーのボタンを押して港を置く操作。
