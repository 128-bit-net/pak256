# 歩行者

街の道路の脇を歩く人（`obj=pedestrian`）の作り方です。

## 何が作れるか

道路を歩く人の絵です。出るのは見た目だけで、旅客の数には影響しません。アドオンで足すと、pak256 の物と混ざって出ます。pak256 の今の物は男性・女性・子どもの 3 種です。

## 大きさと基準点

**大人の背丈は 16px** です（256px のタイル。決定: 2026-11-27、[記録](https://github.com/128-bit-net/pak256/blob/main/docs/records/2026-11-27_pedestrians.md)）。実物の大きさ（約 10px）より大きく、車両の「手本の 2 倍」（24px）より小さい値です。扉（約 12px）より少し高く、バス停の屋根（約 17px）の下に収まります。pak256 の子どもは 12px、女性は 15px です（手本の値）。

![バス停の脇に立つ歩行者と、後ろの建物の扉](/spec/pedestrians.png)

画面は OTRP の最新版を 3 倍に拡大した物です（2026-11-27）。絵はどれも仮です。道路は同梱の AMI（CC BY 4.0、作者 128na）です。

### 足元の位置

歩行者は道路の左右どちらかの端寄りを歩きます。位置は dat の `offset`（道路の端からの距離。1/256 タイル。道路の端はタイルの端）と、絵の足元の位置の**両方**で決まります。

**絵は、進む向きの右側で、道路の端から `offset`/256 タイルの所に足元を描き**、同じ値を `offset` に書きます。足元の点は、[道路の車両](./vehicle-road.md) の「車線の位置」のずれを (128 − `offset`) ÷ 48 倍した分だけ、基準点（256 のセルの (128, 192)）からずらした点です。

`offset=18` の例（倍率は 110 ÷ 48）:

| キー | 基準点からのずれ（px） |
|---|---|
| `s` | (-55, -27.5) |
| `w` | (55, -27.5) |
| `sw` | (0, -27.5) |
| `se` | (-55, 0) |
| `n` | (55, 27.5) |
| `e` | (-55, 27.5) |
| `ne` | (0, 27.5) |
| `nw` | (55, 0) |

![足元の点が道路の端から offset の距離にあることを示す図](/spec/pedestrian-foot.png)

`offset` は、白線の外の路肩に収まる値にします。同梱の AMI の生活道路（`ami_road_local`、`ami-256-alpha.9`）では舗装がタイルの端まであり、白線の外の路肩は端からおよそ 0〜40（0〜0.156 タイル）です。pak256 の 3 種は 12・18・24 と変えて、同じ所に重ならないようにしています。

## 絵

- キーは `image[向き]` で、**8 方向をすべて描きます。** 車両のような 4 方向の代用は無く、書かなかった向きは何も表示されないはずです。
- 層も、冬・気候ごとの絵もありません。
- 歩く動きは、`image[向き][コマ]`（コマは 0 から続けて）と `steps_per_frame` で付けられます。1 つでもこの形を書くなら、8 方向すべてに 1 コマ以上描いてください。pak256 の歩行者は動きを持たず、動きの付いた物は試していません。

## dat のキー

書き方の共通の決まりは [dat の共通のキー](./dat.md) を見てください。

| キー | 内容 |
|---|---|
| `distributionweight` | 出やすさ。省くと 1 |
| `offset` | 道路の端から歩く線までの距離（1/256 タイル）。省くと 20 |
| `intro_year`・`retire_year` | 登場と引退。省くと 1 年と 2999 年 |
| `image[向き]` または `image[向き][コマ]` | 絵 |
| `steps_per_frame` | 動きのコマを送る間隔（動きのあるとき） |

### 例

```
obj=pedestrian
name=example_pedestrian
copyright=あなたの名前
distributionweight=8
offset=18
image[s]=walker.0.0
image[w]=walker.0.1
image[sw]=walker.0.2
image[se]=walker.0.3
image[n]=walker.0.4
image[e]=walker.0.5
image[ne]=walker.0.6
image[nw]=walker.0.7
```

## 本体の動きの注意

- **左側通行のずれは足されません。** 左右どちらを歩くかは人ごとに決まり、左側を歩くときは本体が `offset` から計算して絵を左へずらします。左右どちらでも道路の端から同じ距離になるように、絵は上の決まりで描きます。
- 出るのは、街の建物が旅客を出したとき（`simuconf.tab` の `random_pedestrians`）と、停留所に旅客が着いたとき（`stop_pedestrians`）です。
- まっすぐな道と角の道に出ます。行き止まりと分かれ道のタイルには出ません（そこを通り抜けることはあります）。
- 歩く速さはどの人も同じで、長くても数十秒で消えます。
- 交差点では、直進する人が交わる道路の舗装の上を通ります。
- 1 タイルごとに曲がる斜めの道路では、車線の上を歩く人がいます。絵では直せません。
- 停留所のタイルでは、待合の絵に重なって手前に描かれます。
