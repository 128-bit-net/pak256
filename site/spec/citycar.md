# 街の車

街の中を勝手に走る車（`obj=citycar`）の作り方です。プレーヤーは持てません。大きさと描く位置は [道路の車両](./vehicle-road.md) と同じ考え方です。

## 何が作れるか

自家用車のように、街が道路に出す車です。アドオンで足すと、pak256 の物と混ざって出ます。pak256 の今の物は小型・セダン・大型の 3 種です。

## 大きさと基準点

- **画面の大きさは pak128 の同じ種類の街の車の 2 倍**です。測り方は [車両の大きさ](./vehicle-size.md) の「画面の大きさ」、今の物の目標は同じページの表にあります。
- `length` はありません。車体の長さは目標の長さ（px）のとおりに描きます。
- 描く位置は道路の車両と同じです。**右側の車線の点に車体の前の端を置き、後ろへ伸ばします**（[道路の車両](./vehicle-road.md) の「車線の位置」の表）。
- 256 のセルで足ります。

![道路を走る街の車（左下の緑）と、郵便のトラック（赤）・バスを並べた画面](/spec/road-citycars.png)

画面は OTRP の最新版、等倍です（2026-11-27）。絵はどれも仮です。道路は同梱の AMI（CC BY 4.0、作者 128na）です。

## 絵

- キーは `image[向き]` で、**8 方向をすべて描きます。** 車両のような 4 方向の代用は無く、書かなかった向きは何も表示されないはずです。
- 層も、冬・気候ごとの絵もありません。

## dat のキー

書き方の共通の決まりは [dat の共通のキー](./dat.md) を見てください。

| キー | 内容 |
|---|---|
| `distributionweight` | 出やすさ。省くと 1。読み込んだすべての街の車の中で、この値の割合で選ばれる |
| `speed` | 最高速度（km/h）。省くと 80。道路の上限のほうが低ければ、そちらになる |
| `intro_year`・`intro_month`・`retire_year`・`retire_month` | 登場と引退。省くと 1900 年と 2999 年。年表を使う地図で効く |
| `image[向き]` | 絵 |

### 例

```
obj=citycar
name=example_citycar
copyright=あなたの名前
distributionweight=3
speed=50
intro_year=1930
image[s]=car.0.0
image[w]=car.0.1
image[sw]=car.0.2
image[se]=car.0.3
image[n]=car.0.4
image[e]=car.0.5
image[ne]=car.0.6
image[nw]=car.0.7
```

## 本体の動きの注意

- **台数と寿命は pak の `simuconf.tab`（`citycar_level`・`default_citycar_life`）で決まります。** アドオンからは変えられません（遊んでいる人は、表示の設定の交通量で変えられます）。pak256 の値は [docs/config.md](https://github.com/128-bit-net/pak256/blob/main/docs/config.md#%E8%A1%97%E3%81%AE%E8%BB%8A) にあります。小さい街ほど少なくなります。
- 左側通行の地図では、道路の車両と同じに絵がずれます。
- 停留所の後ろなど追い越しできない所では、前の車の後ろに詰まって止まります。追い越せる道では、追い越し車線に出ます。
- 年表を使う地図で、その年に使える街の車が 1 つも無いと、街の車は出ません。
- 曲がりと坂は道路の車両と同じです。直角の曲がりの頂点では、内側の白線に少し掛かることがあります。

## この pak の値の例

出やすさ・速さは手本の値です（合わせる必要はありません）。

## 確かめていないこと

- 本家の Simutrans、右側通行の地図。
- 上の dat の例をゲームで動かすこと。
- 8 方向のうち一部を省いた街の車の見え方。
- 雪の気候の道路、橋とトンネル、一般道と高速道路の上。
