# 縮尺と大きさ

## 縮尺

**縮尺の 1 単位は実物の 1.65m** です（決定: 2026-11-26、[記録](https://github.com/128-bit-net/pak256/blob/main/docs/records/2026-11-26_scale-check.md)）。pak128.Japan の「実物の長さ（m）÷ 1.65」と同じです。

| 項目 | 値 |
|---|---|
| 1 単位 | 1.65m |
| 1 タイル | 16 単位 = 26.4m 四方（本体の `CARUNITS_PER_TILE` = 16） |
| 地面の距離 | 菱形の辺に沿って 1m ≒ 横 4.85px・縦 2.42px。菱形の対角線 256px ≒ 37.3m なので、対角線の向きでは 1m ≒ 6.86px |
| 高さ | 1m ≒ 5.94px（6.86 × 0.866。斜め上から見るため） |
| 地形の高さの 1 段 | 32px（pak256 の `simuconf.tab` の `tile_height = 8`） |

![1 タイル 26.4m と、辺・対角線・高さの px の換算を示す図](/spec/scale.png)

px の値を直に覚えず、**実物の寸法（m）からこの表で換算**してください。

## 何を実寸で描くか

| 物 | 大きさの決め方 |
|---|---|
| 建物・木・地面・道路と線路まわりの寸法 | この縮尺の実寸 |
| 道路と線路の車両 | 画面の上の大きさを手本の 2 倍にする（線路は pak128.Japan、道路は pak128）。実寸より大きくなる |
| 船・飛行機 | 中型の船と飛行機は実寸。大型の船は縮める |
| 歩行者 | 大人 16px |

道路と線路の車両の値は [車両の大きさ](./vehicle-size.md)、歩行者は [歩行者](./pedestrian.md) にあります。船・飛行機の値は、ページを足すまで [大きさの規格の 4 章](https://github.com/128-bit-net/pak256/blob/main/docs/standards.md) にあります。

車両の `length`（本体が車両を並べる間隔）も同じ単位です。線路の車両は「実物の長さ ÷ 1.65」を四捨五入した値なので、長さは実物に比例します。道路の車両の `length` は画面の大きさから決めるので、実物に比例しません。

## 画面での 1 単位の長さ

1 単位（1.65m）の画面の長さは、進む向きで変わります。

| 進む向き | 1 単位 |
|---|---|
| 軸の向き（北・南・東・西） | 横 8px・縦 4px（斜めに 8.9px） |
| 画面で縦の斜め（`se`・`nw`） | 5.7px |
| 画面で横の斜め（`sw`・`ne`） | 11.3px |

pak256 の `simuconf.tab` は `diagonal_multiplier = 724` で、斜めでも 1 単位が地面の同じ長さになります。この値が違う設定では、斜めの長さが変わります。

## pak128 との比

- タイルの画素数は、pak128 の 128px に対して **256px（2 倍）** です。
- pak128 の絵をそのまま使うと、同じタイルの中で半分の大きさになります。
- 車両は、手本の絵の px を 2 倍した大きさが目安です。建物と木は手本の 2 倍ではなく、実物の寸法から換算します。
