# アドオン作者向けの仕様

pak256.LongScale に合うアドオンの作者向けの仕様です。**このリポジトリの道具（`tools/` のスクリプト）を使わなくても**、ほかの描画ソフトと makeobj で作れるように書いています。

pak256.LongScale は α 版で、仕様は変わることがあります。

## 対象

| 項目 | 内容 |
|---|---|
| 本体 | OTRP の最新版（[配布元の Releases](https://github.com/teamhimeh/simutrans/releases) の一覧の一番上の版。プレリリースを含む）の Windows 版で確かめています。本家の Simutrans では確かめていません |
| makeobj | 60.12（本家 125.0 に付く版） |

## 読む順

1. [縮尺と大きさ](./scale.md): 実物の寸法を何 px にするか
2. [タイルとセル](./tile-and-cell.md): PNG のどこに何を描くか。向きの呼び方
3. [絵の共通の決まり](./drawing.md): 光・透明・特別な色・冬の絵
4. [dat の共通のキー](./dat.md): 名前・登場年・気候・画像の指定と、組み方

物の種類ごとのページ（車両・建物・駅など）は順に足します。まだ無い種類は、[大きさの規格](https://github.com/128-bit-net/pak256/blob/main/docs/standards.md) と [docs/](https://github.com/128-bit-net/pak256/tree/main/docs) の各文書を見てください。

## 決まりと手本の値

- **決まり**: 合わせないと、大きさや見え方がほかの物と食い違うこと（縮尺、セルの中の位置、光の向きなど）。
- **手本の値**: pak256 の今の物の値（費用・性能・建物の高さなど）。参考で、合わせる必要はありません。
- **未定**: まだ決めていないこと。「未定」と書きます。自分の判断で作って構いません。

「（決定: 日付）」は、その決まりを決めた日です。理由や比べた画面は、リンク先の記録（リポジトリの `docs/records/`）にあります。

## 許諾とクレジット

pak256 に入れる物の条件（許諾への同意・元データ・クレジットの書き方）は [参加のしかた](https://github.com/128-bit-net/pak256/blob/main/CONTRIBUTING.md) を見てください。自分で配るだけのアドオンには、この条件は掛かりません。ただし pak256 や AMI の絵を元にするときは、[使用許諾](https://github.com/128-bit-net/pak256/blob/main/LICENSE.md) に従ってください。
