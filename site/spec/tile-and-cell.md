# タイルとセル

## 言葉

| 言葉 | 意味 | 値 |
|---|---|---|
| タイル | 地図の 1 マス。地面の菱形 | 絵の幅 256px、平らなときの高さ 127px（256 のセルの行 129〜255） |
| セル | PNG を切り分けるマス。makeobj の `pak256` などの数字 | pak256 の自前の物は 256px。`cell_size` で物ごとに変えられる |

ゲームのタイルの大きさは、makeobj の数字ではなく、地面（`Outside`）の絵の幅で本体が決めます。

## 256 と 512 のセル

![256 のセルと 512 のセルの中の、菱形の頂点と基準点の位置](/spec/tile-and-cell.png)

- 256 のセルの中の菱形の頂点は、上 (128, 128)・左 (0, 192)・右 (256, 192)・下 (128, 256) です。上と下の頂点の座標の差は 128px で、実際に塗るのは行 129〜255 の 127 行です。
- **基準点は (128, 192)**（タイルの中心）です。車両の位置、建物と木の足元は、この点を基準に描きます。
- 絵が 256 のセルに収まらないときは **512 のセル**を使います。256 のセルの絵を真ん中に置き（座標に +128）、画像の指定に位置合わせ `,-128,-128` を付けます。基準点は (256, 320) です。
- 256 より大きいセルは、本体が自動で中央に寄せることはありません。位置合わせを必ず付けてください。
- セルの大きさは pak に残りません。同じ絵なら、256 のセルに描いた物と、512 のセルの中ほどに描いて位置合わせした物は、同じ pak になります。

512 のセルを使う物の例は、20m の車両（`length=12` 以上はほとんど）と、高い煙突です。指定の書き方は [dat の共通のキー](./dat.md) の「画像の指定」を見てください。

同梱の AMI の道路・線路は 512 のセルで組まれています。基準点と縮尺は同じです。

## 高さがセルに収まる上限

256 のセルに収まる高さは、足元がタイルのどこかで変わります。

| 足元の位置 | 高さの上限の目安 |
|---|---|
| タイルの奥の角 | 約 21m |
| タイルの中央 | 約 30m |

これを超える物は 512 のセルに描きます。

## 向きの呼び方

地図の方角と画面の向きは、次のように対応します。

| 地図の方角 | 画面の向き（菱形の辺） |
|---|---|
| 北 | 右上 |
| 東 | 右下 |
| 南 | 左下 |
| 西 | 左上 |

車両などの 8 方向の絵のキーは、進む向きで決まります。

| キー | 画面の上で進む向き |
|---|---|
| `s` | 左下 |
| `w` | 左上 |
| `n` | 右上 |
| `e` | 右下 |
| `sw` | 左（真横） |
| `ne` | 右（真横） |
| `se` | 下（手前） |
| `nw` | 上（奥） |

建物と停留所の向きの番号は、種類ごとに意味が違います。種類ごとのページ（足すまでは [docs/](https://github.com/128-bit-net/pak256/tree/main/docs) の各文書）で扱います。
