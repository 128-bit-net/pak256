# 駅・停留所

道路の停留所・路面電車の停留所・線路の駅・モノレールの駅の作り方です。信号は [信号](./signal.md)、港はこのページでは扱いません（ページを足すまで [docs/stations.md の「港」](https://github.com/128-bit-net/pak256/blob/main/docs/stations.md#%E6%B8%AFpak256-%E3%81%AE%E7%89%A9)）。

## 何が作れるか

`obj=building`・`type=stop` の物です。`waytype` で、どの道に建てる停留所かが決まります。

| 種類 | `waytype` | 扱う物の例 | pak256 の今の物 |
|---|---|---|---|
| 道路の停留所 | `road` | 旅客・郵便、貨物 | バス停、トラックの荷役所 |
| 路面電車の停留所 | `tram_track` | 旅客 | 路面電車の停留所 |
| 線路の駅 | `track` | 旅客 | 駅 |
| モノレールの駅 | `monorail_track` | 旅客 | モノレールの駅 |

扱う物は `enables_pax`（旅客）・`enables_post`（郵便）・`enables_ware`（貨物）で選びます。駅舎のような停留所の隣に建てる拡張の建物（`type=extension`）は、このページでは扱いません。

道路と線路は、pak256 に同梱の AMI（CC BY 4.0、作者 128na）の 256 版を使います。道路の白線や線路の位置は AMI の版で変わります。この説明は 2026-11-27 の AMI `ami-256-alpha.9` に合わせています。

![線路の駅に停まる 2 両の列車](/spec/station-rail.png)

![荷役所に停まる石炭のトラック](/spec/station-truck.png)

![路面電車の停留所と架線の柱](/spec/station-tram.png)

![モノレールの駅に停まる車両](/spec/station-monorail.png)

画面は OTRP の最新版、等倍です（2026-11-27。荷役所の画面は 2 倍に拡大）。絵はどれも仮です。道路・線路・桁・架線は同梱の AMI（CC BY 4.0、作者 128na）です。バス停にバスが停まる画面は [道路の車両](./vehicle-road.md) にあります。

## 大きさと基準点

停留所は **1×1 タイル**の部品で、長い駅はこれを並べて作ります。大きな駅舎（2×1・2×2）は、線路の脇に置く `type=extension` の 1 つの建物にして、ホームの 1×1 と組み合わせます（決定: 2026-11-27）。線路の上に載る形の駅舎は作りません（`type=stop` の建物は 1 タイルしか置けないため）。駅舎の大きさは「実物の長さ ÷ 26.4m」で決めます。道から離して置く `type=extension` の建物は、`needs_ground=1` を書かないと下の地面が描かれません。基準点は 256 のセルの (128, 192) です（[タイルとセル](./tile-and-cell.md)）。寸法は [縮尺と大きさ](./scale.md) で px にします。

停留所の絵は **道路や線路そのものを描きません**。下の道がそのまま見えるので、車両の通る所を空けて、脇に設備を置きます。置く位置は、軸に直交する向きの位置 c（タイルの幅を 1、画面の上の側が 0）で決めます。

![上から見た 1 タイル。線路の駅と、道路・路面電車の停留所で、設備を置く帯](/spec/station-position.png)

- **道路・路面電車の停留所**: 設備は白線の外（路肩）に置き、白線より内側（道路の中央の側）には何も描きません。画面の上の側（奥）には待合や小屋などの高い物を置けます。画面の下の側（手前）に背の高い物を置くと、足元が路肩でも画面で白線に重なるので、**低い歩道だけ**にします。白線の位置（0.156 と 0.844）は AMI の生活道路の値です。ほかの道路の種類では確かめていません。
- **線路の駅**: 線路はタイルの中央（c = 0.43〜0.57）を通ると見て、画面の下の側の脇にホームを置きます。
- **モノレールの駅**: ホームは車両の床の高さに合わせた台にします（車体は c = 0.42〜0.58、ホームは 0.62〜0.96）。
- **路面電車の停留所**: AMI の路面軌道の架線の柱が、直線の升の中央の奥の路肩に立ちます。奥の側の屋根・柱・ベンチは、軸の向きの位置 a（0〜1）が 0.39〜0.61 の所に置きません。

pak256 の今の物の高さ（手本の値）です。

| 物 | 高さ |
|---|---|
| 線路の駅のホーム | 0.9m |
| モノレールの駅のホーム（車両の床の高さ） | 2.4m |
| バス停の歩道 | 0.15m |
| バス停・路面電車の停留所の屋根（上端） | 2.9m |
| 荷役所の積み降ろし場 | 1m |

20m の車両 2 両は 24 単位（1.5 タイル）です。線路の駅は **2〜3 タイル**並べて置きます。

## 絵

### 向き

停留所は、道の向きと、並べた停留所の端かどうかで、**8 通り**の絵を持ちます。NS は画面で左下〜右上、EW は右下〜左上の道です。南は画面の左下、北は右上、東は右下、西は左上です（[向きの呼び方](./tile-and-cell.md)）。

![線路の駅の 8 通りの向きの絵](/spec/station-layouts.png)

| 番号 | 向き |
|---|---|
| 0 | NS の中ほど |
| 1 | EW の中ほど |
| 2 | NS の南端 |
| 3 | EW の東端 |
| 4 | NS の北端 |
| 5 | EW の西端 |
| 6 | NS の両端（1 つだけ置いた駅） |
| 7 | EW の両端（1 つだけ置いた駅） |

「端」は線路の行き止まりではなく、**並んだ停留所の連なりの端**です。1 つだけ置くと、両端の絵（6・7）が出ます。端の絵は小さな縁を足すだけにして、車両の通る所はふさぎません。

### 層

絵は 2 枚に分けます。`backimage` は車両の**奥**に描かれ、`frontimage` は車両の**手前**に描かれます。奥の側の設備は `backimage`、手前の側の設備は `frontimage` に描きます。

### 地面と季節

- 停留所は道の升に建てるので、下の地面は道の物がそのまま描かれます。`needs_ground` は書きません。
- 冬や雪の絵の枚数と使われ方は建物と同じです（[絵の共通の決まり](./drawing.md) の「冬と雪の絵」）。pak256 の今の停留所は冬の絵を持ちません。

### 道具の絵（アイコン）

ツールバーのアイコンは、透明な所の無い角丸の四角を、セルの左上の角から置いた形にします。pak256 では 192px の四角です。本体は、絵の見える範囲を `icon_height`（pak256 は 48）に収まる倍率で縮めるので、透明な所があると枠がずれて見えます。詳しくは [GUI の絵](https://github.com/128-bit-net/pak256/blob/main/docs/gui.md) と [大きさの規格の 7 章](https://github.com/128-bit-net/pak256/blob/main/docs/standards.md) を見てください。

## dat のキー

書き方の共通の決まりは [dat の共通のキー](./dat.md) を見てください。停留所で使うキー:

| キー | 内容 |
|---|---|
| `obj`・`type` | `building`・`stop` |
| `waytype` | 上の表 |
| `dims` | `1,1,8`。3 つめが向きの絵の数。**省くと、置こうとしたときに本体がエラーで止まります** |
| `enables_pax`・`enables_post`・`enables_ware` | `1` で扱う |
| `level` | 停留所の大きさの元の値。容量は `level` × 32（`capacity` で直接書けます）。pak256 の値は仮 |
| `intro_year`・`retire_year` | 登場と引退 |
| `allow_underground` | 地下に建てられるか。`0` は地上だけ、`1` は地下だけ、`2`（省いたとき）は両方 |
| `noinfo` | `1` にすると、建物の情報の窓を出しません |
| `icon`・`cursor` | 道具の絵と、置くときのカーソル。`cursor` の見え方は確かめていません |
| `backimage[向き][y][x][高さ][コマ]` | 車両の奥の絵 |
| `frontimage[向き][y][x][高さ][コマ]` | 車両の手前の絵。高さは 0 だけ |

`cost`・`maintenance` は、省くと本体の既定です。値の目安は**未定**です。

### 例: 線路の駅

画像 `station.png` が 8 列（向き）× 3 行で、0 行が奥の絵、1 行が手前の絵、2 行の 0 列が道具の絵の形です。

```
obj=building
name=example_station
copyright=あなたの名前
type=stop
waytype=track
enables_pax=1
level=2
intro_year=1900
noinfo=1
allow_underground=2
dims=1,1,8
icon=> station.2.0
backimage[0][0][0][0][0]=station.0.0
backimage[1][0][0][0][0]=station.0.1
backimage[2][0][0][0][0]=station.0.2
backimage[3][0][0][0][0]=station.0.3
backimage[4][0][0][0][0]=station.0.4
backimage[5][0][0][0][0]=station.0.5
backimage[6][0][0][0][0]=station.0.6
backimage[7][0][0][0][0]=station.0.7
frontimage[0][0][0][0][0]=station.1.0
frontimage[1][0][0][0][0]=station.1.1
frontimage[2][0][0][0][0]=station.1.2
frontimage[3][0][0][0][0]=station.1.3
frontimage[4][0][0][0][0]=station.1.4
frontimage[5][0][0][0][0]=station.1.5
frontimage[6][0][0][0][0]=station.1.6
frontimage[7][0][0][0][0]=station.1.7
```

道路の停留所は `waytype=road` にして、扱う物を選びます。貨物の荷役所は `enables_ware=1` だけにします。

## 本体の動きの注意

- **向きの数と建てられる升**: このページでは、`dims` の 3 つめが 2・4・8・16 の停留所を扱います。pak256 は 8 だけを使います。OTRP にはもっと多い向きの数（斜めの道や坂に建てる形）もありますが、作り方は**未定**です。

| 向きの数 | 形 | 建てられる升 |
|---|---|---|
| 2 | 端の絵なし（0 = NS、1 = EW） | 直線の道と行き止まり |
| 4 | 行き止まりの駅 | 行き止まりの升だけ |
| 8 | 上の表 | 直線の道と行き止まり |
| 16 | ホームを置く側が 2 通り | 確かめていません |

- **曲がりと分かれ道**: 2・4・8 の停留所は、曲がりには建てられません。路面電車の停留所も、街の道がつながって交わる升には建てられません。
- **坂**: 8 通りまでの停留所は坂に建てられません。
- **置き換え**: 同じ升に別の停留所を重ねると、容量の大きい物へ置き換えられます。容量が同じか小さい物は断られます。
- **名前と保存データ**: 保存データは建物を `name` で指します。配った後は変えないでください。

## 確かめていないこと

- 本家の Simutrans、右側通行。
- 上の dat の例をゲームで動かすこと。
- 16 通りの向き、坂に建てられないこと、`type=extension` の建物。
- 2 通りの停留所を行き止まりに建てることと、容量の大きい物への置き換え。
- ツールバーのボタンを押して置く操作と、置くときのカーソル。
- 地下に建てた停留所の見え方。
- 道路の停留所の置き方は AMI の生活道路だけで見ています。ほかの道路の種類、斜めの道、リニア・狭軌の駅は確かめていません。
